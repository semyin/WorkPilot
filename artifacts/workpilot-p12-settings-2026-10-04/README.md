# WorkPilot P12 项目设置迁移预览

版本 `0.1.0-alpha.12.3`，Windows x64 开发预览，数据版本仍为 11。本批没有新增提交或推送，最近已推送的提交仍为 `c1720cc`。

保留整个 preview 文件夹，打开 [WorkPilot 程序](preview/workpilot-desktop.exe)。如果旧版仍在运行，体验新版前先从旧版托盘选择“退出”。

设置 → 项目设置与记忆迁移：选择项目、模型和已确认记忆，设置口令并导出；在目标文件夹先预览，再确认导入为新项目。现有项目、配置和实际文件不会被覆盖；模型密钥需要时重新填写。确认导入会使勾选的记忆生效，通用记忆用于所有项目，项目记忆只绑定新项目。

上一批“文件与终端 → 修改历史”的文件历史备份/恢复仍可使用。新设置包不包含会话、技能、定时计划和项目实际文件，也不代替历史备份；完整迁移、签名更新、安装兼容和跨平台验证仍在计划中。

操作与边界见 [项目设置迁移说明](../../docs/development/P12-项目设置迁移.md)，实际结果见 [P12 验证记录](../../docs/development/P12-验证记录.md)。旧 [文件历史预览](../workpilot-p12-history-2026-10-04/README.md) 与 [安装器](../workpilot-p12-browser-setup-2026-10-04/README.md) 保留原版本，没有把旧安装器标作本版。

本机结果：130 项核心测试、9 项脚本检查通过，2 项特定环境检查保持忽略；设置迁移的引擎/实际桌面各 4 组通过，原文件历史的引擎 5 组、桌面 4 组复验通过。原生文件选择框和真实跨机器使用仍待体验，Windows 本机结果不代表 macOS/Linux 已验证。
