# WorkPilot P11 记忆与定时任务预览

这版增加了工作台顶部的**“定时任务”**，保留此前的记忆、办公预览、浏览器、技能与插件。

## 打开新版

先在旧版托盘菜单选择“彻底退出 WorkPilot”，再打开 [WorkPilot.exe](preview/WorkPilot.exe)。保留整个 `preview` 文件夹。

打开“定时任务”，新建一个“只执行一次”的计划，选择已配置的模型，将时间设在几分钟后，写好要求并保存。可以先用“生成一段简短的工作提示”验证，之后再配置实际项目。

## 可以看到什么

- 支持一次、每隔几分钟、每天、每周指定日；可选择时区并预览下次时间。
- 每个计划单独选择项目、模型、工作模式和三档权限；默认请求审批。
- 可以编辑、停用、立即运行和删除。每次运行生成独立任务，从历史打开完整结果。
- 上一次还在执行或等你输入/审批时，下一次会跳过并写明原因。
- 隐藏窗口后仍执行。彻底退出后停止，重新打开只记录错过，不自动补跑。
- 模型或项目设置改变后，需要重新保存计划，确认新的设置用于以后运行。

停用或删除计划不会取消已开始的任务；如需停止，在任务工作台操作。删除计划保留历史。查看更早记录时暂停历史列表的自动刷新，重新选择计划即可回到最新记录。

## 数据和验证范围

数据版本为 11，升级前自动备份旧数据库。旧程序不能打开升级后的数据，原 P10 与 P11 记忆交付目录和清单仍保留。测试使用专用临时目录，没有修改真实用户数据。

旧办公、文档和浏览器运行环境及许可证按原清单核验后随包保留。当前提供完整本机目录，没有另压一份 ZIP。安装、整体备份迁移和包体积处理在 P12 继续。

本版是 Windows 开发机预览，尚不是正式 V1。实际电脑睡眠/唤醒、真实模型的记忆质量、跨平台和用户体验仍待验证；本机进程暂停测试不代替整台电脑睡眠。通知方式和此前图片服务等待办继续保留，不必现在逐项确认。

实际检查与已知边界见 [P11 验证记录](../../docs/development/P11-验证记录.md) 和 [定时设计](../../docs/development/P11-定时设计.md)。程序与源码对应关系见 [交付清单](source-and-binary-manifest.json)，本机检查见 [证据汇总](evidence/summary.json)。
