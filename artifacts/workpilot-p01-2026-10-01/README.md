# WorkPilot P01 Windows 预览

本次增加任务和过程的可靠保存。可以在左侧打开已保存任务，重新启动后继续查看完整历史。

## 打开

- [启动 WorkPilot](preview/WorkPilot.exe)
- [下载便于保存的压缩包](WorkPilot-P01-Windows-x64.zip)

解压后保留 WorkPilot.exe 与 workpilot-engine.exe 在同一目录，再双击 WorkPilot.exe。使用本机已有的 WebView2；不需要安装 Rust，也不需要填写模型密钥。

这是开发预览，还不是安装版或 Windows V1。旧 P00 交付目录保留不动；不要把两个版本误认为同一个窗口。

## 可以体验什么

1. 点击“开始验证”，可以停止，也可以等它结束。
2. 点击左侧“已保存任务”，右侧会显示保存的过程；展开条目查看详情。
3. 点击“彻底退出”，再打开，之前的记录仍然存在。
4. 点击窗口关闭只隐藏到托盘，后台继续运行。

异常退出后的记录会显示“已中断”，没有结果的工具会标为“待核对”。这一阶段暂不提供模型对话、真实工具执行和点击继续，后续按计划接入。
