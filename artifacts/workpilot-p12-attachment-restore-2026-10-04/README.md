# WorkPilot P12 附件随任务恢复预览

程序 `0.1.0-alpha.12.13`，数据版本 11。Windows x64 开发预览，尚未通过 P12 整体验收。

新版任务档案把本组附件原文一起加密保存；单任务和同项目多助手恢复时重新解析，重建每个任务自己的附件关联，旧消息引用和模型读取可继续使用。未发送、排队及已移除状态保留，恢复本身不联系模型，仍需手动继续。

先从托盘彻底退出旧版 WorkPilot，再打开本目录的 `preview/workpilot-desktop.exe`。进入“设置 → 任务与助手档案迁移”，导出带附件的新档案；目标先导入查阅，再预览、确认恢复。附件清单列出格式、大小、所属任务和已移除状态。恢复后的“文件成果与图片”中可以查看可用附件原文。

旧版没有附件原文的档案需要从原任务重新导出。每包最多 64 个附件（包括已移除项），单个 32 MiB，与会话正文合计最多 256 MiB；超限或损坏会明确拒绝，不截断。原文在目标机器重新加密保存。当前项目文件与文件历史仍使用各自迁移入口；旧路径只保留来源说明。

标准检查 173 项 Rust、14 项 Node 通过，2 项环境专用检查继续忽略；新增附件恢复存储检查 4 项。最终打包引擎 33 组、原生桌面 20 组通过，Windows 构建和打包完成。 模型部分使用本机可重复的三协议模拟服务，不代表本批真实商业服务或跨机器验收。新增中英界面截图已查看。
