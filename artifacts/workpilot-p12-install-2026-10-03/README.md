# WorkPilot P12 安装与环境开发预览

本批增加设置中的“环境检查与诊断”，以及程序内固定版本的 Python、Git、Node 和办公工具。版本为 `0.1.0-alpha.12`，数据版本仍为 11。

已完成正式构建和本机安装检查，可打开：

- [Windows 安装器](WorkPilot_0.1.0-alpha.12_x64-setup.exe)，约 674 MiB。使用前先从托盘退出当前 WorkPilot，避免两份程序同时打开同一份数据。
- [直接运行预览](preview/workpilot-desktop.exe)。请保留整个 preview 文件夹。

在“设置 → 环境检查与诊断”中，点击“检查环境”或“完整核验文件”，还可导出本机报告。安装器和程序二进制仅保留本机，不进入 Git；源码、许可来源、摘要清单和真实验证证据入库。

113 项 Rust、9 项脚本检查通过；已安装程序的桌面 3 组、Office 5 组和安装卸载 5 组检查完成。项目文件、额外文件及 6 个测试数据库均保留。Git 普通命令在受限权限下仍有兼容失败，已明确记录；完全访问命令和工作区的审批提交流程验证成功。

安装器是当前用户、未签名的开发预览。默认卸载保留项目和 WorkPilot 数据。浏览器仍需要已有 Chrome/Edge；Chromium 候选因缺少完整组件许可未随包。Python 含标准库，不含 pip；MinGit 不含 Git Bash；其他插件的额外依赖须单独核对。

完整 P12 还需补齐浏览器分发与 Git 受限命令兼容，实现签名更新、数据迁移和加密文件版本恢复/清理，并完成干净系统安装验证。浏览器连接组件仍需手动注册/解除注册；卸载器的可选桌面缓存删除不能代替完整历史清理。不能将本批当作正式 Windows V1。用户待确认项继续集中记录，本轮无需操作。
