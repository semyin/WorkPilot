# WorkPilot P12 项目文件迁移预览

版本 `0.1.0-alpha.12.6`，数据版本 11；Windows 开发预览，不是正式 V1。

运行本目录 `preview/workpilot-desktop.exe`，保留整个 preview 文件夹。

1. 选择已绑定项目文件夹的任务，打开“文件与终端 → 文件迁移”。
2. 在文件夹中勾选文件，设置保存位置和口令，生成加密文件备份。
3. 切换到目标项目任务，打开备份、输入口令和目标子文件夹，预览每个文件的新位置。
4. 没有冲突时提交导入，在下方“操作与确认”批准或查看结果。“完全访问”会直接执行。
5. 在“修改历史”查看此次新建文件。重复导入同一备份到同一任务/位置只返回原操作，保留后来修改。

支持中文目录、空格、图片等二进制和空文件。最多 128 个文件，单文件 64 MiB，合计 256 MiB。不会覆盖已有同名文件；中途停止可能已导入部分文件，这些文件和历史保留。口令至少 12 个字符，软件不保存，请单独保管。

范围和规则见 [项目文件迁移说明](../../docs/development/P12-项目文件迁移.md)，检查结果见 [P12 验证记录](../../docs/development/P12-验证记录.md)。`evidence` 保存实际检查和截图，`source-and-binary-manifest.json` 保存源码/程序摘要。
