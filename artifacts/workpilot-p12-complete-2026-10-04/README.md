# WorkPilot P12 整合版

版本 **0.1.0-alpha.12.15**，数据版本 11。P12 的开发项和本机自动验证已完成；干净 Windows、真实换机和用户体验仍待验收。

## 打开方式

- [Windows 安装器](WorkPilot_0.1.0-alpha.12.15_x64-setup.exe)：当前用户安装，约 1045.3 MiB；卸载默认保留资料。安装器尚无 Windows 发布者证书。
- [直接运行预览](preview/workpilot-desktop.exe)：免安装，保持整个 preview 文件夹完整，约 2.30 GiB。
- [程序内使用说明](preview/使用说明.txt)。

如果旧版 WorkPilot 仍在运行，打开新版前先在它的托盘菜单中选择“退出”；关闭窗口只是隐藏。旧包仍保留。不要让两个版本同时使用默认数据目录。使用安装版或预览二选一即可。

## 这版能看到什么

1. 统一选择项目、模型配置、记忆、任务与助手、当前文件、技能及草稿，形成口令保护包。分别映射原项目与文件夹，保留附件/版本/来源；未决操作逐项人工核对后才允许手动续接，历史命令可分页读取。
2. 扩展迁移包含全部所选旧版本、已卸载记录和未安装草稿；导入后停用、重填凭据，超过旧界面 64 条分页的版本也能迁移与回滚。
3. 版本保留先生成并验证可恢复备份；归档任务整组删除、只读档案移除和未引用内容回收均先预览。清空当前数据/凭据与更新恢复副本清理分开确认，项目及独立任务文件夹受保护。
4. 固定版本 Chromium、完整组件许可与受限 Git 兼容程序随包提供；不替换日常浏览器、不改全局 PATH。环境检查用固定 4 个并行读取任务核验全部文件，显示当前处理文件，原有超时和取消仍有效。
5. 用户主动检查和安装真实签名更新；停止执行后检查数据副本，再一起切换程序和数据。坏包、版本不符、数据被占用和六类中断点有失败恢复，旧副本显式管理。准备阶段另生成安装目录外、带明确确认和结果提示的可双击恢复入口，主程序暂时不可用时也可运行。
6. 新 Windows 安装器携带 9 类运行组件与 WebView2 离线资产；卸载默认保留资料，单独勾选才清空当前历史和凭据。静默/更新卸载不会自动清空。

可先在“设置 → 完整资料迁移”选择一个测试项目，导出后读入到新的文件夹，检查任务、附件和文件历史；需要模型继续工作时重新填写密钥。旧任务不会自动续跑，技能不会自动启用。

“数据清理与恢复初始状态”先展示范围，一般删除输入 DELETE，清空当前数据输入 RESET。版本清理必须先成功保存口令备份。删除迁入文件任务后会释放已失效的内容引用，并保留防重复的删除记录；仍被其它任务或独立档案引用的内容继续保留。清空会删除本机版本密钥，依赖它的旧本地副本可能无法再解密；先导出独立口令保护包。当前数据清理和更新恢复副本管理是两个独立入口，用户项目文件保留。

“软件更新”支持私有 HTTPS 源和本地 .wpupdate 签名包；没有默认公共更新地址。检查、下载核验、停止任务并安装各自独立确认。失败会保留恢复副本，完成后手动重新打开应用。准备更新时会在安装目录外生成 `WorkPilot-Recover-编号.exe` 及说明，并在界面显示准确位置；若切换过程中被强制结束导致主程序打不开，可双击该恢复工具，核对后确认恢复。已完成更新不会因此回退。
