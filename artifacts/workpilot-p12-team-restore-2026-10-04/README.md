# WorkPilot 多助手恢复预览

版本 `0.1.0-alpha.12.12`，数据版本 11。Windows 私有开发预览，P12 尚未整体验收。

运行 [WorkPilot](preview/workpilot-desktop.exe)，请保留整个 preview 文件夹。原运行窗口没有被替换；体验新版时，先从旧窗口的托盘菜单退出，再打开本目录程序。

同一项目、无附件及未决操作的多助手团队可逐一选择模型，预览后恢复。保留分工、嵌套、依赖、失败、接替、交付检查结论、对话和排队消息；全部等待手动继续，原审批不生效，命令执行关闭。已完成、失败、被接替和放弃的分支不会自动重跑。

打开“设置 → 任务与助手档案迁移”，导入并选中团队档案。下方为主任务和每个助手选择本机模型及目标项目，点击“预览团队恢复”，核对后点击“确认恢复为新团队”。然后打开恢复的主任务、查看历史和助手交付，手动点击“继续任务”。已完成主任务须先补充新要求。

模型已有历史时须匹配原协议、模型名称和服务地址，本机密钥需自行配置。项目文件请先迁移；历史文字中的原绝对路径不自动替换。重复恢复返回同一团队；恢复本身不连接模型、不写项目文件、不启用旧定时安排。

标准检查 169 项 Rust、14 项 Node 通过，2 项环境专用检查仍忽略；身份一致性补强后另行复核 6 项团队恢复存储检查。最终打包引擎 28 组、原生桌面 16 组通过，构建和打包完成。 本机三协议模拟模型用于稳定验证，不替代真实云端验收。中英桌面截图已逐张核对。
