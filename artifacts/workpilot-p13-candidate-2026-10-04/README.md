# WorkPilot P13 Windows 候选版

版本：`0.1.0-alpha.13.2`，数据版本：11。当前处于本机集成验收中，正式 Windows V1 发布仍以项目验收记录为准。

此目录保留 alpha.13.2 的历史程序和证据；后续修正文件版本参数错误提示后的当前候选见 [r2](../workpilot-p13-candidate-2026-10-04-r2/README.md)。本目录已中止的约十分钟稳定性样本不算四小时通过，也不接续到 r2 计时。

## 怎么打开

保留完整 `preview` 文件夹，双击其中的 `workpilot-desktop.exe`。安装版文件会在安装器校验通过后列在本页；不要只复制一个程序文件。

旧 P12 和 P13 首轮预览独立保留。不同版本共用正式资料时，不要同时打开；开发验收使用单独的测试资料目录，不会把测试模型配置放进你的正式资料。

## 这轮增加和修复了什么

- 任务主面板与侧栏同步显示状态。点击停止先显示正在停止，收到引擎真实结果后再显示已结束；切任务时，旧请求不会把新页面覆盖掉。
- 提供通知中心、Windows 系统通知和托盘提示。三种渠道可分别设置；完成、错误、需要补充输入和需要审批都有对应入口。
- 图片设置可选择标准 Images 接口或阿里云百炼图像接口。后者支持实际图片下载和参考图编辑，新图片作为独立成果保存。
- 补齐三协议、三模式、三档权限的组合检查，真实服务与固定测试服务分别记录。

系统通知需要正确安装身份，Windows 的通知开关和勿扰状态也会影响显示。便携预览会说明系统通知是否可用，软件内与托盘入口仍然保留。点击通知只打开任务，不会代替你批准或继续执行。

## 开始使用

1. 在设置里填写你自己的模型地址、接口类型、模型名称和密钥。先做连接检查。
2. 添加一个测试用项目文件夹，选择聊天、规划或执行模式。首次默认请求审批。
3. 输入目标。运行中发新消息会排队，可以选择引导插队；需要结束时点击停止。
4. 使用文件、浏览器、技能、记忆和定时任务面板。第一次连接日常 Chrome 或 Edge，需要主动加载并授权对应扩展。
5. 关闭窗口后任务继续在托盘运行。托盘里的退出会真正关闭；重开后中断任务需要手动继续。

图片生成在图片服务设置中单独配置。百炼 Qwen Image 选择对应接口类型、PNG 格式和模型支持的尺寸。生成或编辑需要按当前权限确认；报错后不会自动重试或换服务。
