# WorkPilot P13 Windows 候选版 r2

版本：`0.1.0-alpha.13.3`，数据版本：11。这里是本轮 Windows 集成候选版，正式验收状态以 [P13 计划](../../docs/plans/13-Windows首版验收.md) 为准。

本目录保留 r2 历史候选。复查发现正常等待助手误发输入提醒、通知设置旧读取覆盖新值，两项修正由 [r3](../workpilot-p13-candidate-2026-10-04-r3/README.md) 接续。r2 的 13 分钟长跑已正常中止，不能算四小时。

## 打开方式

保留完整 `preview` 文件夹，双击其中的 `workpilot-desktop.exe`。不要只复制一个程序文件。安装包生成和核验结果记录在同目录的安装清单中；需要 Windows 系统通知时使用安装版。

不同版本共用正式资料时，请先从托盘退出旧版本，再打开新版本。本轮测试均使用独立资料目录，不会把测试模型设置写入你的正式资料。原 P12、P13 首轮和 alpha.13.2 交付保留。

## 本轮变化

- 主任务面板与侧栏共用任务状态。停止时先显示正在停止，收到实际结束结果后再更新；切换任务不会被旧请求覆盖。
- 增加软件内通知中心、Windows 系统通知和托盘提示，可分别开关。通知可定位任务，点击不会代替你批准、继续或重跑。
- 图片设置可选择标准 Images 或百炼图片接口。百炼真实生成和参考图编辑已取得成果，编辑保存新图片，原图保留。
- 模型把文件版本参数传成文字 `"null"`、`"None"` 等时，明确提示参数格式错误；不会再误报文件已被别人修改，也不会放宽文件保护。
- 补做真实模型、技能创建、记忆、模式与权限、安装和持续运行检查。完整结果和失败范围见 [验证记录](../../docs/development/P13-验证记录.md)。

## 第一次使用

1. 在模型设置中填写服务地址、接口类型、模型名称和自己的密钥，先检查连接和能力。
2. 添加一个测试用文件夹作为项目。选择聊天、规划或执行；首次默认请求审批。
3. 输入一个目标。运行中发送的新要求默认排队，选择“引导”可以优先处理；点击停止会结束当前执行及所属工具。
4. 需要多助手时，在同一任务中分工，可给成员配置不同模型。某成员出错会保留原因，由主任务决定是否新建接替成员。
5. 使用文件、浏览器、技能、记忆或定时任务面板。关闭窗口后任务继续在托盘运行，托盘“退出”才会彻底结束；重开后中断任务需要手动继续。

模型报错、额度不足或无法连接时，任务会提示错误并停止，不会自动反复扣费重试或换模型。你调整配置后可以手动继续。

## 通知怎样工作

任务完成、出错、需要输入或审批时，按设置发出提醒。默认系统通知在软件后台时发送；设置可允许前台也提醒。

Windows 系统提醒使用通用文字，不发送任务标题、正文或文件内容。Windows 通知开关、勿扰和安装身份影响显示；免安装版会明确说明系统通知是否可用。软件内通知和托盘入口各自保留。

点击提醒只打开对应任务。旧任务已删除时提示无法定位，不会新建、审批或执行任务。重新启动不会把旧通知批量重发。

## 浏览器、技能和文件

- 专用浏览器使用单独资料，不会复制日常浏览器的账号。连接你已登录的 Chrome 或 Edge，需要你主动加载并授权新版 Companion 扩展。
- AI 创建技能先形成草稿，你确认安装后才能启用。内置创建指导名为 WorkPilot skill-creator；它不是从本机 Codex 偷读个人技能目录。
- 长期记忆先生成候选，由你确认；项目记忆只用于对应项目，删除后新的模型调用不再检索到它。
- Office 文件可读取、生成和查看转换后的页面；完整排版编辑交给外部办公软件。支持格式及限制见 [文件矩阵](../../docs/development/P10-文件与图片设计.md#当前格式矩阵)。
- 备份迁移先预览项目、文件和冲突，再确认导入。密钥需要重新填写，原来的审批不会迁成新电脑上的执行许可。

## 真实兼容范围和已知限制

真实模型的结论绑定具体服务、模型、接口与程序版本。当前使用用户授权的阿里云工作空间；接口名称相同不代表其它服务自动通过。当前完整结果集中在 [P13 验证记录](../../docs/development/P13-验证记录.md)。

GLM 5.3 与当前服务的 Chat 接口组合可以给出工具提案，但文件写入样本反复返回不合法的版本参数，程序正确拒绝。不能把这个模型提案探针通过写成实际文件协作通过；也没有足够证据将根因只归给模型或只归给服务中转。

百炼 Qwen Image 3.0 的生成与参考图编辑使用 PNG。其它供应商、模型和复杂图片质量需要分别验证，不会因同一接口名称被宣称兼容。

当前开发机为 Windows 11 x64。干净 Windows、物理另一台电脑、整机睡眠和实际系统通知点击、日常账号及用户体验仍按 [验收矩阵](../../docs/development/P13-验收矩阵.md) 核对。独立资料目录不等于干净系统，自动截图不等于用户亲自验收。macOS/Linux 属于后续阶段。

安装器未购买 Windows 发布者代码签名；现有更新包的签名检查属于另一项能力。没有公开自动更新站点，软件也不会自行升级。
