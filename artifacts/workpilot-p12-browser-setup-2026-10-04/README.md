# WorkPilot P12 浏览器连接安装补充版

程序版本 `0.1.0-alpha.12.1`，Windows x64 私有开发预览，数据版本仍为 11。P12 首批已提交并推送 `01e6b2f`；此目录保存之后的独立交付。旧程序和历史清单保留。

运行入口：[Windows 安装包](WorkPilot_0.1.0-alpha.12.1_x64-setup.exe)，或完整 preview 文件夹里的 [WorkPilot 程序](preview/workpilot-desktop.exe)。程序包留在本机，没有上传到 Git。体验新版时，先从旧版托盘选择“退出”，再打开新版。

在设置中打开“Chrome / Edge 连接设置”，可以检查和配置本机连接、移除当前安装的配置，以及复制/打开扩展文件夹。浏览器中仍需加载 Companion 并明确连接目标网页；“本机已配置”不代表已经取得页面控制权。旧版占用连接时会提示原位置，当前版不覆盖它。

卸载只清理指向当前安装目录的 Companion 记录。其它预览版的连接、Probe、用户项目和任务记录保留。移除本机配置不立即断开已有网页连接，可在扩展中断开或停止对应任务。

环境文件核验改为独立检查程序。系统读取文件长时间不返回时，会结束本次检查并说明“尚未确认完整”，不会一直占用后台检查位置或显示旧的成功结果。系统底层卡顿来源仍在跟踪，实际复验结论见验证记录。

本版仍未解决专用浏览器完整分发、通用 Git 受限命令、签名更新、完整数据迁移与加密版本恢复/清理。干净 Windows、macOS/Linux 和日常浏览器用户体验仍待验证，不是正式 V1。

本批实际检查和证据见 [P12 验证记录](../../docs/development/P12-验证记录.md)。具体源码、程序与安装器摘要在本目录的交付清单中记录。

当前使用 zlib 压缩，完整安装包约 833 MiB。对同一批工具的一次本机比较中，打包从约 13 分 28 秒缩短到 3 分 55 秒，代价是比 LZMA 包大约 157 MiB；这是单次开发机结果，不是跨机器保证。Office、WebView2 和工具许可材料均保留。
