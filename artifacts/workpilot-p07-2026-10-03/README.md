# WorkPilot P07 开发预览

这版新增项目文件编辑、修改历史与恢复、真实终端、Git 所选提交和本机运行预览。日期：2026-10-03，已在 Windows 11 x64 自动验证，用户体验待确认。

## 打开与体验

先从旧版托盘菜单选择“彻底退出”，再双击 [WorkPilot.exe](preview/WorkPilot.exe)。保留旁边的配套程序，也可取用 [完整预览压缩包](WorkPilot-P07-Windows-x64-preview.zip)。旧 P00—P06 程序原样保留。

1. 选择一个绑定了文件夹的项目及任务，点击对话上方“文件与终端”。初次体验可以先绑定专门的测试文件夹。
2. 在“文件”中打开或新建文本，修改后保存。任务需为执行模式；需要确认时，查看下方“具体操作”，再确认执行。
3. 在“修改历史”中查看前后差异，选择恢复修改前或修改后的版本。外部修改发生后，会要求先重新读取，编辑草稿不会直接消失。
4. 在“终端”输入 PowerShell 命令，例如 Write-Output '你好，WorkPilot'，运行后查看输出。长命令可点“停止”。
5. Git 项目可以查看差异并只提交勾选文件；当前不自动推送。运行网站时，在完全访问任务中登记空闲服务端口，启动成功后打开运行预览。

手工文件和终端操作不调用模型；让 AI 自动完成任务时仍需配置自己的模型服务。测试密钥不随包提供。

## 当前边界

- 文本编辑不超过 256 KiB，单文件版本不超过 64 MiB；命令快照有总量及目录排除范围。办公文件支持版本保存和恢复，可用外部软件打开，内置内容预览后续实现。
- 终端支持命令和输出，暂不支持持续交互输入。长服务运行期间，该项目其它受管理写入排队；可停止服务后编辑。
- 关闭主窗口后保留在托盘，命令继续；彻底退出停止所属后台进程。重开后不会自动重复中断命令。
- 数据结构为版本 7，首次升级自动备份数据库。旧程序不要打开新版数据库；跨机器迁移加密文件版本按 P12 实现。
- 这是开发预览，当前只有 Windows 实测。通知偏好和操作体验继续集中确认，本次不用立即回复。
