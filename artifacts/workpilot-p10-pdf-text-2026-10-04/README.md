# WorkPilot PDF 数字读取修复预览

版本 `0.1.0-alpha.12.8`，数据版本 11；整合此前 P12 功能的 Windows 开发预览，不是正式 V1。

运行本目录 `preview/workpilot-desktop.exe`，保留整个 preview 文件夹。

本版修复新生成 PDF 中英文附近的数字、金额、编号被读错，以及数字间距偏宽的问题。中文字体、分页、表格文字和文件来源保留；项目文件、附件成果和历史备份功能继续可用。

体验方法：在已绑定项目目录的任务中要求生成含 `Portable generated output 42`、`Invoice A00123456789Z: 1234.56 -17 25/17 100%` 的 PDF；到“文件成果与图片”打开成果，核对文字内容和图像预览。原文件不会被此修复追改，旧版生成过的 PDF 需要重新生成才能获得正确的数字文字。

检查结果见 [P10 验证记录](../../docs/development/P10-验证记录.md)，当前进度见 [文档索引](../../docs/README.md)。`evidence` 保存修复前后测试、独立 PDF 工具核验、页面图像和实际桌面记录；`source-and-binary-manifest.json` 保存本批源码与程序摘要。

此前 [附件迁移预览](../workpilot-p12-media-2026-10-04/README.md) 及更早交付原样保留。本批未制作新安装器；真实图片服务、用户体验、干净系统和 macOS/Linux 的待验收范围不变。下一步继续 P12 完整会话/多助手和关联资料迁移、清理及更新。

项目文件与附件成果迁移已先提交并推送 `b116e08`；此后的 PDF 修复仍在本地，未追加提交推送。
