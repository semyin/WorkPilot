# WorkPilot P06 开发预览

这版把已有引擎、工具和多助手整合成日常工作台：左边管理项目和任务，中间对话，右边看权限、协作、成果和完整记录。

日期：2026-10-02。已在 Windows 11 x64 验证，仍为开发预览。

## 打开与体验

双击 [WorkPilot.exe](preview/WorkPilot.exe)，保留旁边的 `workpilot-sidecar.exe`。也可取用 [完整预览压缩包](WorkPilot-P06-Windows-x64-preview.zip)。

1. 在“模型服务”配置自己的模型。测试密钥不随包提供。
2. 左侧新建项目，绑定一个测试文件夹，再新建任务。可选择聊天、规划或直接执行。
3. 运行时补充要求会排队；尚未处理的消息可以编辑、取消或点击“引导”。
4. 右侧查看具体审批、成员交付、步骤和成果。完整记录可搜索正文、分页面查看和导出。
5. 用“设置”切换语言和外观；左右面板可拖动或收起。任务可搜索、重命名、归档和恢复。

关闭窗口后留在托盘，任务继续。托盘菜单“彻底退出”才会停止后台执行；再次打开后，中断的任务需要人工继续。

## 已验证与边界

- 原生桌面验证了项目、附件、消息编辑/取消、归档、英文审批、错误与后台执行。十万条合成记录和约 2.1 MB 正文仍可输入、检索和停止任务。
- 附件目前支持小型文本。图片、Office、项目文件编辑/回退、浏览器、技能插件和正式安装包仍按后续阶段推进；没有可用功能的入口会明确说明。
- 系统通知方式留待你统一确认。本次不用立即回复；有空时再集中体验文件夹选择、复制到外部软件、界面阅读和窗口行为。
- 数据结构升到版本 6，升级前自动备份。旧版本不要打开新版数据库；P00—P05 原包保持原样。
