# WorkPilot P05 开发预览

本版新增真正的多助手协作。主助手可以按需分工，每个成员独立选择模型、保存过程和交付成果；失败记录保留，可明确建立新助手接手。支持依赖等待、运行数量上限、整组停止和手动继续。

日期：2026-10-02。仅验证 Windows 11 x64，仍为开发预览。正式工作台属于 P06，Windows V1 仍需完成 P00—P13。

## 打开与体验

双击 [WorkPilot.exe](preview/WorkPilot.exe)。请保留同目录的 `workpilot-sidecar.exe`，两者一起使用。也可下载 [完整预览压缩包](WorkPilot-P05-Windows-x64-preview.zip)。

1. 在“模型服务”中配置自己的服务、模型与工具能力。测试密钥不会随包提供。
2. 打开“任务执行”，选择“直接执行”，填写一个专门的测试文件夹。可让主助手自动分工，也可选“先创建并设置分工”。
3. 在协作面板查看职责、模型、依赖和状态；“查看交付”显示摘要、用量与实际文件来源；“打开过程与审批”进入该成员的独立过程。
4. 点击“停止任务”停止整组。关闭窗口只隐藏到托盘；彻底退出后停止，重新打开需手动继续。

可尝试：“分派两个成员，分别整理这个测试目录里的两份资料，再安排一个成员等它们交付后汇总。请检查每份成果后告诉我结果。”

成员需要审批时，打开对应成员查看具体操作。成员不能通过分工获得比主任务更高的权限。任务开始前可覆盖成员目标和模型；失败或中断后可说明原因，建立新的接替助手。

## 已验证与边界

- 引擎协作验证涵盖独立成员、依赖、失败隔离、接替上限、停止恢复、同文件冲突与两个项目同时工作。
- 真实阿里云模型通过三个独立接口配置完成三成员协作，实际文件结果为 42；主助手检查交付并回读确认。
- 文本文件、命令、三档权限和审批继续沿用 P04。团队历史当前保留，暂不提供单独删除成员的操作。
- 浏览器完整驱动、插件、办公文件、正式安装包与 macOS/Linux 实机适配仍按后续阶段推进。普通完全访问命令仍使用系统账户权限，不代表所有外部操作都可回滚。

SQLite 数据结构已升级到版本 5，迁移前自动备份。请勿用旧交付打开新版数据库。本目录保留独立交付；P00—P04 原包未改动。
