# WorkPilot P04 Windows 开发预览

日期：2026-10-02。P04 代码和自动测试完成，保留用户体验确认。不是正式 V1，未发布、未推送。请使用本目录的新版本；P00—P03 原交付保留不改。

## 打开与体验

双击 [WorkPilot.exe](preview/WorkPilot.exe)，保留同目录的引擎程序。已有任务数据会先备份再升级到 schema 4；不要用旧预览打开新版数据库。数据默认在本应用 alpha 开发目录，测试使用隔离目录。

1. 在“模型服务”设置服务与模型，完成工具调用测试。
2. 进入“任务执行”，新建任务并选择“直接执行”。
3. 填入一个专门测试用文件夹的完整路径，使用默认“请求审批”。例如让助手创建 hello.txt，写入“你好 WorkPilot”，然后回读。
4. 审批卡会展示目标与具体内容。点击“批准并继续”后才写文件；任务里可看“文件修改前后”。
5. 可继续体验“帮我批准”的独立审查记录、拒绝操作、停止与手动继续。命令入口需主动勾选，作用范围在设置里显示。

本轮开发验证使用用户授权提供的阿里云配置，仅保存在隔离测试凭据区；预览不附带密钥，也没有复制真实测试账号配置。

## 已验证与尚未覆盖

完整检查和证据见 [P04 验证记录](../../docs/development/P04-验证记录.md)，当前边界见 [工具与审批设计](../../docs/development/P04-工具与审批边界.md)。三协议真实文本、工具、多轮、图片和真实文件流程均使用同一阿里云工作空间中的 qwen3.8-flash 实测；不代表所有服务商或模型已兼容。

当前受管理工具支持 UTF-8 文本；每次写入 64 KiB、读取文件 1 MiB。命令使用项目清单校验，限制 1024 文件/64 MiB，无链接。完整文件回滚、二进制成果、插件与浏览器分别在后续 P07—P10。系统隔离不是虚拟机：系统允许的公共资源仍可能可读。完全访问命令使用当前账户权限。
