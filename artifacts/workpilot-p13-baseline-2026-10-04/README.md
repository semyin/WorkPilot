# WorkPilot P13 集成验证预览

版本 **0.1.0-alpha.13.1**，数据版本 11。开始 Windows 首版的集成验证，尚不是已验收的正式 V1。

## 打开方式

打开 [workpilot-desktop.exe](preview/workpilot-desktop.exe)，保留整个 preview 文件夹。关闭窗口只会隐藏到托盘；如旧版正在运行，先从旧版托盘选择“退出”，避免两个版本使用同一份默认资料。

这轮提供独立免安装预览。原 [P12 整合版及安装器](../workpilot-p12-complete-2026-10-04/README.md) 保持原样；尚未生成新的 P13 安装器，旧安装打包命令会拒绝混入 P13 版本。

## 你能看到的变化

任务完成后，如果没有新的要求，“继续任务”不再允许重复点击。发送新要求后继续正常处理；中断任务仍可以手动继续，迁移恢复后的排队要求也可以接续。此前这个入口会误报成模型配置问题，本轮已修正。

完整迁移、文件历史、技能插件、定时、图片入口和签名更新等原有功能继续保留。新增的性能工具属于开发检查，不要求用户输入额外配置。

## 怎样验收

本轮标准检查 206 项 Rust、11 项 Node 和 3 项 PDF 通过，另有 3 个环境/专用进程入口保持标记忽略；工作台及多助手恢复共 13 组回归通过。正常界面每项 20 次测量、1/4/8 任务和 1/3/8 助手、20 次实际工具停止，以及分开归属的桌面/引擎/WebView 资源均有证据。全部 480 个代码文件不超过 1000 行。准确口径、失败及未覆盖项见验证记录。

- [用户体验清单](../../docs/development/P13-用户体验清单.md)：每项都有操作步骤、预期结果和反馈方式，可以分批体验。
- [验收矩阵](../../docs/development/P13-验收矩阵.md)：区分已有自动检查、真实服务和仍缺的条件。
- [本轮验证记录](../../docs/development/P13-验证记录.md)：实际数字、失败修正、测试范围和下一步。
- [最终核对摘要](evidence/summary.json)：各套报告、程序一致性和旧交付保留检查。
- [源码、程序及资源清单](source-and-binary-manifest.json)：核对本轮受测文件和版本。

短时固定模型负载不等于真实模型体验或四小时稳定性。真实不同模型协作、真实图片服务、日常 Chrome/Edge 授权、干净 Windows、物理换机、睡眠/时区、人工体验和通知选择继续集中待验收；macOS/Linux 没有实机验证。

还发现停止后侧栏状态会比主面板晚刷新，已记录为下一步处理项。当前停止反馈测量针对任务标题状态，不能说所有位置都同步更新。
