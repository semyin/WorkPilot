# WorkPilot 任务与助手档案预览

版本：`0.1.0-alpha.12.9`。日期：2026-10-04。实际验证环境：Windows 11 Home x64；数据版本 11。这是 P12 的一批预览，不是 Windows 正式 V1。

## 打开体验

先从托盘彻底退出你正在使用的旧 WorkPilot，再打开 [workpilot-desktop.exe](preview/workpilot-desktop.exe)。请保留整个 preview 文件夹，不能只移动 exe。本轮测试保留了原用户程序，没有替你关闭它。

设置 → 任务与助手档案迁移：停止一组任务后选择主任务、输入两次口令并备份。再选择档案、输入口令、核验预览并确认导入，在下方按类别展开消息、助手、执行记录和完整正文。可以勾选“选择已归档的任务”，也可以给已导入档案重新加密另存。

**本批导入后只能查阅，不能继续执行。** 原任务和文件不修改，不触发模型或工具。当前项目文件、附件原文件与加密文件历史请使用各自迁移入口；完整引用恢复仍在推进。不要因为本次档案导入成功就删除原数据目录。

## 实际结果与限制

- 标准检查 151 项 Rust、14 项 Node 通过；2 项专用环境测试仍忽略。引擎 21 组（含附件短目录复验）、桌面 11 组通过，另保留长目录 DOCX 预览失败；完整范围见 [验证记录](../../docs/development/P12-验证记录.md)。
- 旧 DOCX 预览在较长测试目录中两次出现组件异常退出，较短目录两次通过；原因仍未定，记录为 T-P10-04，不能认定已经修复。原文件没有丢失。
- 新生成 PDF 数字修复、现有文件/附件/设置/历史迁移继续保留。旧交付与程序清单不改。
- 本轮没有安装器、干净系统、物理换机、原生选择框人工体验或非 Windows 验收。没有提交或推送。

档案每包最多 33 个任务、5 万条记录、4096 份正文、256 MiB；记录索引最多 8 MiB。本机最多保留 128 份导入档案，超限会拒绝，不截断内容。本机导入后的记录按现有内容库方式保存，口令保护的是导出的备份文件。
