# WorkPilot P12 附件与成果迁移预览

版本 `0.1.0-alpha.12.7`，数据版本 11；Windows 开发预览，不是正式 V1。

运行本目录 `preview/workpilot-desktop.exe`，保留整个 preview 文件夹。

1. 选择任务，打开“文件成果与图片 → 附件迁移”。
2. 勾选附件或成果，设置保存位置与口令，生成加密备份。
3. 切换到目标任务，打开备份，输入口令和可选的名称前缀，先预览再导入。
4. 回到“附件与成果”查看内容和来源；同名资料会独立保留，不覆盖已有资料。
5. 要继续让 AI 使用资料，点击“加入下一条消息”，再主动保存/发送消息。

可迁移上传文档、图片、读取过的项目文档和生成成果的原始快照。最多 64 项、单项 32 MiB、合计 256 MiB。不会改写项目文件，也不会自动把资料发送给模型。口令至少 12 个字符，软件不保存，请单独保管。

重复导入只返回原回执，不恢复后来移除的资料。确认前取消不留下半批附件；已完成的导入保留成功结果。任务运行时请先停止，再导入。

范围见 [附件与成果迁移说明](../../docs/development/P12-附件与成果迁移.md)，真实检查见 [P12 验证记录](../../docs/development/P12-验证记录.md)。证据保存在 `evidence`，源码及程序摘要位于 `source-and-binary-manifest.json`。
