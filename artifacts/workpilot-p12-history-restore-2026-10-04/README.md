# WorkPilot P12 文件历史随任务恢复预览

程序 `0.1.0-alpha.12.14`，数据版本 11。Windows x64 开发预览，P12 尚未整体验收。

任务档案现在同时保存主任务和助手各自的文件修改历史，包括修改前后原字节、原时间和来源。恢复时选择目标项目，可预览清单；导入只增加历史记录，当前文件不变。恢复后查看差异，再按权限恢复具体版本。

先从托盘彻底退出旧版 WorkPilot，再打开本目录的 `preview/workpilot-desktop.exe`。进入“设置 → 任务与助手档案迁移”，导出新档案；目标先导入，再选择本机模型和项目，预览确认恢复。随后在“文件与终端 → 修改历史”查看差异，选择具体版本恢复。

原项目文件夹离线也能导出已保存历史。旧版任务档案仍兼容；没有随包历史的旧档案需要从原任务重新导出以补齐。每包最多 128 条历史，修改前后每份最多 64 MiB，与附件/会话一起去重合计 256 MiB；超限拒绝，不截断。原文用目标自己的密钥加密保存。当前项目文件仍使用原文件迁移入口；多个原目录需要后续分别映射，不能自动合并。

标准检查 177 项 Rust、14 项 Node 通过，2 项环境专用检查仍忽略；新增文件历史恢复存储检查 4 项。最终打包引擎 36 组、原生桌面 20 组通过，Windows 构建和打包完成。 新增中英界面截图已查看。模型测试为本机模拟服务，不代替商业服务或物理跨机验收。
