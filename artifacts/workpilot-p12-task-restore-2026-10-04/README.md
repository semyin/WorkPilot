# WorkPilot 单任务恢复预览

版本 `0.1.0-alpha.12.11`，数据版本 11。P12 进行中，Windows 私有开发预览。

运行 [WorkPilot](preview/workpilot-desktop.exe)，请保留整个 preview 文件夹。

本轮没有替换你正在运行的旧窗口。体验新版时，请先从旧窗口的托盘菜单彻底退出，再启动本目录程序。

在“设置 → 任务与助手档案迁移”导入档案后，选择本机模型和项目，点击“预览任务恢复”，核对后“确认恢复为新任务”。随后可打开任务、查看原对话与排队消息，手动点击“继续任务”。当前支持没有附件、没有助手且无未决操作的单任务。

新任务默认请求审批、命令执行关闭。旧审批和定时安排不会启用；恢复本身不连接模型、不写项目文件。重复恢复返回原任务。原已完成任务没有新消息时，需要先补充要求。请先迁移所需项目文件、重新配置模型凭据。

标准检查 163 项 Rust、14 项 Node 通过，2 项环境专用检查仍忽略；最终打包引擎 20 组、原生桌面 16 组通过，构建/打包完成，中英文截图已核对。 实际范围见 [验证记录](../../docs/development/P12-验证记录.md)，完整行为与限制见 [设计说明](../../docs/development/P12-任务与助手档案迁移.md)。
