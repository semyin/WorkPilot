# WorkPilot P11 记忆开发预览

这是 P11 的第一部分：**可确认、可修改、可撤销的记忆**。本地定时任务还没有实现，P11 仍在进行中。

## 打开新版

先在旧版托盘菜单中选择“彻底退出 WorkPilot”，再打开 [WorkPilot.exe](preview/WorkPilot.exe)。保留整个 `preview` 文件夹。

工作台顶部有“记忆”按钮。可以先手动添加一句“回答先给结论，再给一个例子”，点击“保存并确认”。也可以在配置好模型的任务中说“请把我的这个习惯提出为记忆候选”，随后到“记忆”面板查看来源并确认。

## 本次能看到的变化

- AI 提出的内容显示“待你确认”，确认后才供后续模型调用使用。
- 选择项目时显示该项目和通用记忆；其它项目不会被一起读入。
- 可以搜索、修改、拒绝、删除、查看来源任务和版本记录。
- 勾选“显示已删除”，从“历史与撤销”恢复旧版本。恢复候选仍需确认。
- 可以导出所选范围当前有效的已确认记忆，保存成 JSON 文件。

修改从下一次模型调用生效；已经发出的请求不会撤回。删除停止主动检索，但会保留可撤销历史、过去对话和备份。

## 数据与交付

数据版本为 10。首次升级会先按既有规则备份旧数据库；旧程序无法读取升级后的数据。此前交付目录和清单均保留。本版没有改动真实用户数据来测试，自动测试全部使用独立目录。

办公预览、浏览器及文档工具的原运行环境和许可证按旧清单核验后随包保留。当前提供完整本机预览目录，未另外压成新的 ZIP；后续安装与体积精简仍在 P12。

实际检查见 [P11 验证记录](../../docs/development/P11-验证记录.md)；交付文件与源码版本见 [清单](source-and-binary-manifest.json)。这是 Windows 开发机预览，尚不等于正式 V1、真实模型内容质量、用户体验或其它平台验收。

下一步继续 P11 的定时计划、发生记录、托盘触发、错过不补跑和退出恢复。既有真实图片服务配置及其它待体验项继续保留。
