# WorkPilot P02 Windows 开发预览

本版新增“模型服务”：配置自己的模型接口、保存密钥、读取模型列表、测试文字/工具请求/图片输入，查看回复、错误和用量。实现及本机模拟测试已完成；真实模型服务仍待你明确配置后验证。

## 打开和试用

1. 打开 [preview/WorkPilot.exe](preview/WorkPilot.exe)。保留同目录的 workpilot-engine.exe。
2. 点击左下方“模型服务”，添加服务，填写地址、接口类型、模型名称和密钥。
3. 保存配置，点击“测试文字”。需要时继续测试工具请求和图片输入。
4. 右侧可以查看结果和停止调用；重新打开程序后仍能查看记录。

密钥只在本机设置页输入，无需发到聊天里。导出配置不带密钥。工具测试不会运行电脑上的工具。关闭窗口隐藏到托盘；“彻底退出”才会停止引擎。

当前不是正式安装版，也不是完整 AI 办公助手。正式任务执行、多助手和工具权限按后续阶段实现。程序需要 Windows WebView2，当前电脑已具备；干净系统安装验收在 P12/P13。

默认仍使用 WorkPilot 的 development 数据目录，首次打开会从 schema 1 升级到 2，并先备份。P01 原交付已保留；旧程序不能读取新版数据库，如需退回必须使用旧阶段备份。

- 三类协议的分片、工具关联、错误、超时和取消通过本机模拟服务验证。
- Windows 桌面中的密钥保存/清除、三协议测试、导入导出、重启和并发限制已实际运行。
- 原桌面的双语、历史保存、隐藏、退出、崩溃恢复回归通过。
- **未连接真实模型账户**，未测试 macOS/Linux。模拟通过不等于所有服务都兼容。
