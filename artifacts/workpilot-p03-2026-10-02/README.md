# WorkPilot P03 Windows 开发预览

本版新增“任务执行”：模型可以连续选择工具、读取结果并决定下一步；可以排队消息、点击引导、停止和手动继续。执行过程会保存，意外退出后先核对未完成操作。

本机样本与 Windows 桌面测试通过。真实模型服务还没有明确配置，P02/P03 保留“待外部条件”，不是正式 V1。本轮没有推送。

## 打开与查看

1. 双击 [WorkPilot.exe](preview/WorkPilot.exe)，保留同目录的 workpilot-engine.exe。
2. 点击左下“任务执行”，新建任务。模型服务仍从左下“模型服务”配置，密钥只需填在本机设置里。
3. 可选“聊天”“先规划再执行”“直接执行”。规划得到步骤后，点击“开始执行计划”才执行。
4. 运行中发送新要求会排队，点击消息的“引导”会调整当前工作。停止或失败后，点击“继续任务”才重新发起执行。
5. 右侧展开步骤查看输入和结果，“完整事件”可分页查看全部过程。

当前内置工具只读固定样本、计算和保存任务内测试文字，不操作真实项目文件或终端。可以勾选“启用内置样本工具”验证完整流程；服务需要支持工具调用。新任务默认不勾选。

窗口右上角关闭后隐藏到托盘，任务继续。“彻底退出”会中断，再打开不会自动请求模型或重做工具。对于不确定操作，继续会先查执行凭据；没有凭据时才需要人工核对。

暂时不需要你完成真实服务验收。后续集中补测时，可用已明确配置的真实模型测试普通对话，以及“读取内置 numbers 样本、计算总和、保存到任务样本区”这类完整循环。不要把本机测试截图当作真实模型成功记录。

## 文件与兼容

- [便携压缩包](WorkPilot-P03-Windows-x64.zip)：解压后启动 WorkPilot.exe。
- preview：桌面与独立引擎，必须成套保留。
- tools：开发者使用的只读数据检查程序。
- evidence：本次实际检查结果与截图。
- [源码与程序校验清单](source-and-binary-manifest.json)：本地基准提交、工作区源码和程序 SHA-256。

程序需要 Windows WebView2，当前电脑已具备；全新系统安装验收在 P12/P13。默认沿用 development 数据目录，打开时会升级为 schema 3，升级前先备份。P00/P01/P02 的旧程序与产物没有被覆盖，旧程序不能直接读取 schema 3；退回需使用对应旧备份。
