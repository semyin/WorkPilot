# WorkPilot 办公预览与长目录修复版

版本 **0.1.0-alpha.12.10**，2026-10-04，Windows 开发预览。数据版本 11；P10/P12 仍在实施，不是正式 V1。

本版修复深层文件夹下 Word、Excel、PPT 预览失败，以及文档工具在长路径中首次准备失败。原文不搬动、不修改；预览使用独立短临时目录，结束后清理，异常退出也有后续回收。失败时能区分预览组件退出，不再误报原文件丢失。

保留上一批整组任务与助手的加密档案迁移、分类查阅及再次导出；这些档案仍只能查阅。新生成 PDF 的数字文字修复也保留，旧 PDF 不自动改写。

## 如何运行

如需体验，先从旧版托盘选择“退出”，再打开 [WorkPilot](preview/workpilot-desktop.exe)，保留整个 `preview` 文件夹。进入任务的“文件成果与图片”，加入办公文件，查看原版式预览。无需立即操作；开发测试使用隔离数据，原有程序没有被关闭。
