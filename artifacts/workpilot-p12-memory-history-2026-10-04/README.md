# WorkPilot P12 记忆历史迁移预览

版本 `0.1.0-alpha.12.4`，数据版本 11；Windows 开发预览，不是正式 V1。

运行本目录 `preview/workpilot-desktop.exe`，保留整个 preview 文件夹。进入“设置 → 项目设置与记忆迁移”，选源项目，再勾选“包含记忆历史与未生效记录”。可选择候选、已拒绝、已删除记忆及历史版本，导入前会显示当前状态和版本数量。

确认导入后只有已确认且未删除的记忆生效，其他条目保持原状态。导入后可在“记忆”中查看、恢复旧版本；已删除条目需勾选“显示已删除”。恢复候选仍需再次确认。旧格式设置包仍可读取，历史模式包需本版或更新版本读取。

每次最多 128 条记忆、每条 256 个已保存版本、全包 2048 个版本及 1 MiB 明文设置；超限或旧版本属于其他原项目时明确拒绝，不截断历史。模型密钥需重填，项目权限重设为请求审批，当前项目文件保持原样。

操作与边界见 [迁移说明](../../docs/development/P12-项目设置迁移.md)，实际结果见 [P12 验证记录](../../docs/development/P12-验证记录.md) 和本目录 `evidence`。源码/程序摘要记录于 `source-and-binary-manifest.json`。
