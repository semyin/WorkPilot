# WorkPilot P12 技能与插件迁移预览

版本 `0.1.0-alpha.12.5`，数据版本 11；Windows 开发预览，不是正式 V1。

运行本目录 `preview/workpilot-desktop.exe`，保留整个 preview 文件夹。

1. 打开“技能与插件 → 技能与插件迁移”，选择需要备份的当前安装版本及配套文件。
2. 设置保存位置和口令，生成扩展备份。
3. 在目标项目选择一个绑定了文件夹的任务；只有全局扩展时可以不选任务。
4. 打开备份并预览范围、依赖、权限与文件，确认导入。
5. 导入项先保持停用。检查资源、重新填写凭据，再按依赖顺序启用；实际执行仍需要相应审批。

同名记录会阻止整个批次导入，重复导入不会多添一份或重设启用状态。每批最多 32 个扩展、2048 个文件、合计 64 MiB 原始内容；超限会明确报错。原有项目设置、记忆历史及文件历史备份继续可用。

操作与边界见 [技能插件迁移说明](../../docs/development/P12-技能插件迁移.md)，实际结果见 [P12 验证记录](../../docs/development/P12-验证记录.md)。本目录 `evidence` 保存检查记录，`source-and-binary-manifest.json` 记录源码和程序摘要。

此前 [记忆历史预览](../workpilot-p12-memory-history-2026-10-04/README.md) 及更早交付保持历史状态。本批没有制作新安装器。完整会话、多助手记录、所选项目文件、扩展旧版本/草稿、统一引用与多项目映射、版本清理和更新仍待接续。
