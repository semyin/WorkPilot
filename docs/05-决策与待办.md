## 2. 已被替代的旧规则

| 旧规则 | 最新有效规则 | 原因 |
|---|---|---|
| 关闭窗口中断任务 | 关闭窗口隐藏到托盘，普通与定时任务继续；彻底退出中断 | Q43 明确修改 |
| 电脑操控在基础引擎后紧接实现 | 首版不做原生电脑操控，放入 P16 | Q29 明确修改 |
| 先单助手可用版，再增加多个助手 | 底层可先验证单循环，正式 V1 必须包含多助手 | Q08 要求 |
| 模型失败自动有限重试或切备用模型 | 主模型失败直接中断；子助手失败按 Q26 隔离接替 | Q18、Q26 修改 |
| 仅中文，或语言支持留到后续 | 首版中英文切换 | Q38 选择 B |
| 较大工具环境使用时再下载 | 首版所需环境尽量随安装包提供 | Q39 选择 B |

重新打开隐藏中的窗口不需要“恢复任务”，因为任务仍在运行。只有真正中断的任务才由用户点击继续；这样同时满足 Q14 与 Q43。

## 5. 明确标记为工程建议的默认值

以下不是额外产品确认门槛，可在实现验证后记录调整：

- 定时任务默认不重叠运行，错过触发不自动补跑，保留可手动运行入口。
- 子助手替换、最大协作深度、同时运行数量采用有限上限；默认值依据 P05 测量确定。
- 普通任务模型与审批模型通过角色配置选择；未指定审批模型时显式使用已配置默认值，不做故障时隐式回退。
- 模型/工具/浏览器大输出使用磁盘引用和按需加载，完整历史可检索；保留期限和磁盘上限作为设置公开。
- 更新前暂停新调度并等待或中断现有任务，数据库备份成功后再迁移。
- 界面主题建议支持浅色、深色及跟随系统；沿用已有确认的应用图标。
- 首版模型协议覆盖与具体服务兼容清单分开；原生图片接口可单独配置，不强迫用户把图片模型伪装成聊天模型。

## 8. P01 实施决定

2026-10-01，主要开发者按 P01 计划实施，不改变首版范围。本轮用户要求需要确认的项目先记录、独立工作继续，最后集中处理。

| 项目 | 实施选择 | 范围和后续影响 |
|---|---|---|
| 数据保存 | SQLite WAL/FULL，单独线程和容量 32 的队列 | 不在异步执行线程做阻塞读写；慢磁盘仍可能推迟持久化回执 |
| 状态与事件 | 同一事务更新；先提交再发送 | P03/P04/P05 接入时必须使用保存层操作，不能绕过事务单写状态 |
| 类型共享 | Rust 类型通过 ts-rs 12.0.1 生成 TypeScript，检查生成文件是否一致 | 更改字段必须重新生成 |
| 本地数据库 | rusqlite 0.40.2，随程序编译 SQLite；迁移前使用 SQLite 备份接口 | 程序较 P00 增大，用户无需另装 SQLite |
| 凭据 | keyring 3.6.3，Windows/macOS/Linux 显式选择系统后端，不提供明文回退 | Windows 假密钥实测；Mac/Linux 仍待对应平台验收 |
| 内容对象 | P01 先实现 UTF-8 文字，64 KiB 单行、256 MiB 单对象，超限报错 | 二进制文件、分块策略和用户保留设置在 P07/P10/P12 扩展 |
| 恢复 | 未结束工具标为待核对，活动执行标为中断，排队/引导保留 | 不在启动时自动执行；真正的继续在 P03 |
| 删除 | 清理任务记录及无引用内容，只处理专用对象目录 | 用户项目源码始终保留；去重墓碑防止迟到重试重建任务 |
| 开发导出 | 版本化事件 JSONL 和只读检查工具 | 不宣称已实现 P12 包含附件的整机导入导出 |
| 库版本 | 锁定 rusqlite、ts-rs、keyring、uuid、sha2 等依赖 | 不采用运行时自动更新，也不擅自改变用户技术基线 |

本阶段没有新增需要用户立即决定的产品选项。Q44 通知方式仍在集中待确认清单中；P02 真实模型验证需要可用服务配置，届时通过明确的配置入口提供，不探查其他软件账号。
