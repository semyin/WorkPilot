## 2. 已被替代的旧规则

| 旧规则 | 最新有效规则 | 原因 |
|---|---|---|
| 关闭窗口中断任务 | 关闭窗口隐藏到托盘，普通与定时任务继续；彻底退出中断 | Q43 明确修改 |
| 电脑操控在基础引擎后紧接实现 | 首版不做原生电脑操控，放入 P16 | Q29 明确修改 |
| 先单助手可用版，再增加多个助手 | 底层可先验证单循环，正式 V1 必须包含多助手 | Q08 要求 |
| 模型失败自动有限重试或切备用模型 | 主模型失败直接中断；子助手失败按 Q26 隔离接替 | Q18、Q26 修改 |
| 仅中文，或语言支持留到后续 | 首版中英文切换 | Q38 选择 B |
| 较大工具环境使用时再下载 | 首版所需环境尽量随安装包提供 | Q39 选择 B |

重新打开隐藏中的窗口不需要“恢复任务”，因为任务仍在运行。只有真正中断的任务才由用户点击继续；这样同时满足 Q14 与 Q43。

## 3. 产品选择与工程默认值

技术基线和功能范围没有新的未决选择。完成十项优化后的工作台提案已获用户确认，无需再次确认相同设计方向；首批正式工作台已经接入，后续按 P06 顺序继续。提案确认或首批改造不代表正式产品通过验收。O-01/Q44 已确认三渠道通知，并在 P13 完成实现与本机自动验证；系统实际显示、托盘提示和点击体验仍待用户验证。

以下为工程默认值，不是额外产品确认门槛：

- 定时任务默认不重叠，错过不补跑，可手动运行。
- 子助手替换、协作深度、同时运行数量采用有限上限，实际配置和边界见 [P05 设计](development/P05-多助手调度与交付.md)。
- 普通任务与审批模型按角色配置；未指定审批模型时使用已配置默认值，不在故障时暗中回退。
- 模型、工具和浏览器的大输出保存为内容引用，按需加载，完整历史可检索；保留与清理范围在设置中公开。
- 更新先停止新调度，等待或中断工作，备份数据后迁移；由用户触发安装。
- 主题支持浅色、深色和跟随系统，沿用已确认图标。
- 协议覆盖与具体服务兼容分别记录；图片服务独立配置。
- 迁移预览、导入、重新授权和恢复分开；凭据不迁移，旧审批不继承，任务不自动继续。分步失败展示已完成部分并凭回执接续，不假称跨文件和数据库的全局事务。
