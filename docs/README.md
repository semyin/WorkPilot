# WorkPilot 开发计划索引

更新日期：2026-10-09

当前阶段：**P06 产品化重做中，尚未进入 P13 正式验收。** 用户指出现界面入口堆砌、缺乏排版和连贯交互，功能可运行不能视为成熟产品。原 [alpha.13.4 交付](../artifacts/workpilot-p13-candidate-2026-10-04-r3/README.md)保留为功能验证基线；下一步按 [P06 重做计划](plans/06-桌面工作台.md)推进。

WorkPilot 面向个人和小团队，是组织模型、工具和多个助手完成工作的通用平台。开发按能力和依赖拆分，不限定某个办公业务。

## 先读这三份

1. [需求基线](00-需求基线.md)：已经确定的产品行为，以及首版包含什么。
2. [路线图与依赖](02-路线图与依赖.md)：按什么顺序实现，哪些阶段依赖前面的结果。
3. [验收与质量标准](04-验收与质量标准.md)：什么证据才算完成，如何由开发者和用户共同验证。

你可以先看每个阶段的“目标、交付物、测试与验收”。“实现任务”主要供后续开发使用；常见技术词在总体架构末尾有解释。

## 分阶段实施顺序

每一份阶段计划都包含前置条件、实现任务、交付物、测试场景、验收条件和阶段边界。

|---|---|---|---|
| P00 | [工程基座与技术验证](plans/00-工程基座与技术验证.md) | 可构建的跨平台骨架，以及关键技术验证记录 | 已验收 |

| P12 | [环境打包与升级迁移](plans/12-环境打包与升级迁移.md) | 随包工具环境、安装更新、导出导入和本地诊断 | 实现与本机自动验证完成；待干净 Windows、物理换机和用户体验验收 |

P03 等阶段的原型用于验证底层能力。Windows 首个正式可用版本是 P00—P13 集成并验收后的结果，包含多助手、两种浏览器接入、图片生成、中英界面、定时任务和随包运行环境。
