# WorkPilot 开发计划索引

更新日期：2026-10-02  
文档状态：P00、P01 已验收；P02 已完成实现与本地测试，待真实模型服务配置；P03—P16 尚未开始。各计划的验收条件与实际完成记录分开阅读。

WorkPilot 是面向个人和小团队的通用 AI 桌面工作平台。用户提出目标，软件组织模型、工具和多个助手完成工作。开发按平台能力和技术依赖拆分，不限定为某一个办公业务工具。

## 怎样继续实施

项目根目录的 [AGENTS.md](../AGENTS.md) 是 Codex 的开发入口，规定先读哪些文档、怎样选择当前阶段、如何验证，以及怎样把进度写回现有文件。换一个任务继续时，仍以文件中的记录和实际代码为依据。

下一步补齐 P02 三协议真实服务验收；后续实现阶段为 P03，先读取 P02 的接口、结果与限制。若用户要求继续独立开发，仍保留 P02 的真实服务缺口，不能用模拟结果替代。每个阶段先核对前置条件，再更新状态和证据链接。普通技术选择由开发者处理；改变产品方向、首版范围或重要交互时交由用户决定。按用户最新要求，需要确认的事项先记录并跳过依赖部分，之后集中确认，不阻止独立工作。

状态使用：未开始、进行中、待外部条件、待用户体验、已验收。任何“已验收”都必须指向测试结果或人工体验记录。失败的验证结果也要保留。

当前仅有一项产品选择未回答：通知方式。暂列“软件内提醒＋系统通知＋托盘提示”为建议，不作为用户已确认的决定，详见 [待办](05-决策与待办.md)。
