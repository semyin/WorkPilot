# WorkPilot 交互与运行规则

更新日期：2026-10-01  
本文把用户选择转化为可实现、可验收的行为。未特别标明的数值默认值是工程建议，不是用户承诺。

## 1. 工作模式与权限模式是两个维度

| 工作模式 | 允许的行为 |
|---|---|
| 聊天 | 对话、理解附件和已授权的只读资料；不主动启动修改、提交或外发任务 |
| 先规划再执行 | 允许必要的只读了解，产生计划；用户明确启动执行后才进入实质操作 |
| 直接执行 | 在用户任务目标和有效权限内直接组织工具执行 |

改变工作模式不自动提升权限。对话文字中声称“已批准”不等于平台收到有效审批。

| 权限模式 | 平台行为 |
|---|---|
| 请求审批（默认） | 对需要授权的动作展示对象、范围和影响；已授予范围内的普通读取不反复弹同一问题 |
| 帮我批准 | 先匹配明确规则，再由审批助手审查；高影响、不明确、审查出错时转用户处理 |
| 完全访问 | 在当前操作系统账户和外部服务已有权限内放开应用层审批限制，仍保留参数检查、执行记录与停止能力 |

完全访问不能绕过操作系统或第三方账户认证。权限建议支持全局默认、项目覆盖、单次任务覆盖；有效范围在执行界面可见。

审批绑定实际动作、参数、目标和规则版本。参数改变必须重新判断。子助手、脚本和插件不能从说明文字中得到更高权限；工具结果也不能替用户修改权限。

## 2. 任务状态

| 状态 | 意义 |
|---|---|
| 排队 queued | 等待运行名额或用户消息的处理时机 |
| 运行 running | 正在请求模型或执行工具 |
| 等待输入 awaiting_input | 等待用户补充资料 |
| 等待审批 awaiting_approval | 已形成具体操作，等待有效批准 |
| 停止中 stopping | 已发出取消，仍在收集工具结束情况 |
| 已中断 interrupted | 用户停止、应用退出或崩溃造成中断，允许人工继续 |
| 失败 failed | 当前执行因模型或不可处理错误结束，保留原因与已有成果 |
| 已完成 completed | 执行结束并记录结果和能够完成的核验 |

界面断开不是任务状态改变。应用重新打开先还原记录，再决定显示运行中任务或已中断任务，不能一律重跑。

## 3. 新消息、排队和引导

1. 当前任务运行时，新消息默认进入队列，明确显示“尚未开始处理”。
2. 每条排队消息可点击“引导”，将其提升为当前执行的调整要求。
3. 引擎在可安全切换的步骤边界交付引导内容，取消尚未开始且已不适用的动作；不把已完成操作伪装成未发生。
4. 对正在请求模型的情况，适配器可取消当前请求，在保存已接收内容后按新要求继续；这是用户引导，不是故障自动重试。
5. 对不可立即中止的外部操作，显示正在等待安全结束，不能先向用户声称“已经停止”。
6. 队列内容、顺序和处理状态需要持久化；崩溃后不能重复执行同一条已处理消息。

## 4. 错误处理

| 错误位置 | 行为 |
|---|---|
| 主助手模型请求 | 提示真实原因并结束本次执行，不自动重试或更换模型 |
| 子助手模型请求 | 停止该助手，其他独立分支继续；依赖该助手的步骤等待主任务处理 |
| 主任务决定接替 | 新建明确可见的助手/尝试，引用原目标、进度与错误；原失败记录不覆盖 |
| 审批助手请求失败 | 本次审查停止、显示错误，原工具不执行，转人工审批 |
| 工具返回可处理错误 | 保存真实错误；主助手可以根据错误选择不同办法，不能伪造工具成功 |
| 工具执行结果不确定 | 先查询或核对结果，再允许用户继续；不能盲目重放有外部影响的操作 |
| 界面与引擎通信中断 | 用事件序号重连和补读，不重新提交已经接受的命令 |

所有协议适配器、HTTP 客户端或引入的 SDK 均需检查并禁用模型请求自动重试。模型故障的测试必须核对请求次数。

主任务可以决定是否接替子助手，但需要受调度上限约束；接替同样失败时不能无上限创建新助手。上限在 P05 验证后确定并可配置。

## 5. 关闭、退出、睡眠与恢复

| 用户动作/系统事件 | 任务行为 |
|---|---|
| 点击窗口关闭 | 隐藏到托盘，运行任务与定时任务继续 |
| 从托盘重新打开窗口 | 显示现有状态，不重复启动正在运行的任务 |
| 点击停止某个任务 | 停止该任务及其子助手、所拥有的工具工作；不影响其他独立任务 |
| 托盘选择彻底退出 | 停止接收新工作，取消运行、保存检查点、结束引擎及受管理工具进程 |
| 强制结束、崩溃、关机 | 不保证最后一条未落盘事件；重启后核对已记录状态并标明不确定操作 |
| 重新启动应用 | 恢复列表，已中断任务由用户点击继续 |
| 睡眠与唤醒 | 软件不能在系统睡眠时保证执行；唤醒后核对运行及错过的调度，不重复执行 |

退出时不关闭用户原有浏览器，不删除已生成文件。若某个远端操作已提交，断开连接不等于远端已撤销，需记录这一状态。

## 6. 定时任务

- 由本机应用中的调度器运行，支持查看下一次执行和历史结果。
- 关闭窗口仍执行；彻底退出、关机或睡眠期间无法保证到点执行。
- 创建计划时记录项目、目标、模型、工作模式、权限、时区与是否启用。
- 定时启动不能绕过三档权限；需要审批时等待用户，不能因为无人看窗口而自动提升权限。
- 工程建议：同一计划默认不重叠运行，错过的触发只记录、不自动补跑；提供手动“立即运行”。
- 应保存触发发生的唯一标识，处理时钟回拨、夏令时和应用重启导致的重复触发。
- 不自动恢复之前因故障中断的运行；计划未来一次新触发是独立运行，历史错误保留。

通知方式 Q44 尚未回答。建议应用内、系统通知及托盘提示；系统通知被拒绝时仍可在应用内处理。

## 7. 文件、版本与人工修改

工具修改前记录目标版本，成功后保存新版本与来源。查看差异时，文本提供内容对比，二进制文件先提供版本和可用预览，不宣称能自动解释所有二进制差异。

用户在外部软件修改文件后，旧版本上的 AI 写入必须检查冲突。恢复旧版本也是一次新修改，需要保护当前文件，不能把用户的新改动直接覆盖掉。

脚本、终端、浏览器下载及插件可能产生文件变化。应用应对所管理项目的工具执行做快照/变更跟踪。只靠文件监听无法保证每一次瞬间改写都被捕获；完整性边界必须经过 P07 验证。

P07 实际入口为任务上方“文件与终端”。保存、恢复、重命名、删除、命令和 Git 提交进入操作记录；手工工作区在请求审批/帮我批准下均需确认，完全访问直接执行。审批与当前文件和权限版本绑定，内容变化后旧确认失效。详情保留具体参数与完整结果。恢复是新版本，原历史不被抹掉。

受管理命令保存执行前后字节；单文件、总量及排除目录有明确限制。长命令运行时该项目其它写入排队，停止后释放。关闭文件工作区或主窗口不停止命令，彻底退出才停止；运行预览随文件工作区关闭而关闭。外部软件的瞬间变化不承诺全部保存，具体边界见 [P07 设计](development/P07-文件历史与开发工作区.md)。

## 8. 完整执行过程

必须可查看：用户指令与排队状态、主/子助手、工具名称和输入输出、权限决定、文件版本、成果、错误、时间、可获得的模型用量。

大输出保存为本地内容对象，界面分页或按需加载，不能为节省界面内存把历史永久丢弃。凭证、认证头等在记录前脱敏；诊断导出不包含密钥。

显示的是服务实际返回的公开内容与应用执行事件，不填造模型未返回的信息。不支持用量或价格的服务应显示“未知/未配置”，不能写成零费用。

## 9. 首次使用与日常路径

首次使用：打开应用 → 选择语言 → 配置模型服务 → 测试连接 → 建立项目 → 选择工作模式和权限 → 开始任务。

日常使用：选择项目 → 新建或继续任务 → 查看过程/审批/成果 → 发送排队消息或引导 → 在需要时停止、恢复或导出。

图片生成需要可用的图片服务配置，不能因为文字模型已接通就假设已经可以生成图片。连接真实浏览器需要用户完成浏览器侧授权。

P12 安装版可先在设置的“Chrome / Edge 连接设置”中配置本机连接，再按页面说明在浏览器加载随包 Companion。界面展示另一安装位置占用时，不覆盖原记录。本机配置完成不等于标签页已授权；卸载只清理自己的本机登记。移除本机登记不强制断开正在运行的页面，停止任务或在扩展中断开才结束当前控制。

## 10. P08 浏览器工作区实际入口

选择绑定项目目录的执行任务，点击顶部“浏览器”。可以启动专用 Chrome/Edge，或生成连接码并在日常浏览器 Companion 扩展中明确连接当前页。连接后选择标签页，读取页面再操作；网页不能自己改变权限。页面变化后的旧目标会拒绝执行。

需要审批时，操作记录显示目标和具体参数；确认后手工操作直接完成，AI 发起的任务点击“确认完成后继续 AI 任务”接续。截图在本地显示；发送给模型前核验其图片能力。上传/下载填写项目内路径，下载可在文件历史恢复。

登录或验证码用“手动接管”，完成后点击恢复并重新读取。关闭窗口继续运行；彻底退出关闭专用浏览器，只断开日常浏览器。停止任务/相关权限变更撤销控制，不自动重连和重放未知外部操作。安装与当前文件大小限制见 [P08 说明](development/P08-浏览器双通道.md)。

## 11. P11 记忆入口与生效时机

工作台顶部“记忆”可查看通用或当前项目记忆。AI 只提出带来源的候选；用户点击“确认记住”，或手工填写后点击“保存并确认”，才成为正式偏好。拒绝的候选仍保留来源，不参与检索。

修改/删除从下一次模型调用生效，已经发出的请求不会撤回。默认列表隐藏已删除项，可勾选“显示已删除”后从历史恢复。恢复待确认版本仍需确认；恢复会新增历史记录，不抹掉之前的修改。导出只包含所选范围当前有效的已确认记忆。

当前删除保留撤销历史，不擦除旧对话或备份。项目记忆与其它项目隔离，不能改变权限或审批规则。

## 12. P11 定时计划入口与发生历史

顶部“定时任务”提供一次、按间隔、每天和每周计划；配置所用项目、目标、模型、模式、权限与时区，保存前可预览下一次时间。新计划默认请求审批。模型或项目配置修改后，应重新保存计划，确认新的设置用于未来执行。

每次运行形成独立任务，可从历史打开完整过程、审批和结果。停用/删除只停止未来触发，已开始任务继续；删除保留历史。同一计划上次仍在运行或等待输入/审批、子助手或文件操作尚未结束时，本次触发跳过并留下原因，手动立即运行也遵守此规则。

关窗后继续，真正退出后停止。再次启动只记录错过，不自动补跑，不继续启动中断的发生任务。手动“立即运行”会创建新任务；用户在历史任务中点继续，则恢复该任务，且仍检查是否与同计划其它任务重叠。

电脑的时区变化不重解释计划时区；夏令时缺失的每日/每周时刻跳过，重复时刻只取较早的一次。调度宽限、暂停观测与未验证的实际睡眠行为见 [P11 定时设计](development/P11-定时设计.md)。查看更早发生记录时暂停历史自动刷新，重新选择计划恢复最新列表。

当前已有应用内发生历史、任务结果和审批入口。通知组合 Q44 继续集中待确认；不能将系统通知未开启理解为允许越过审批。
