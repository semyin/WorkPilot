# P00 图片服务接入方案

结论：可独立实现图片生成适配器，接入位置和至少一条真实接口路线已明确；P00 没有使用用户凭据调用图片服务，也没有把样例图当作生成结果。

## 模块边界

~~~text
图片生成入口 / 助手工具调用
           ↓
平台参数校验与审批
           ↓
图片服务适配器（按服务类型配置）
           ↓
真实图片服务
           ↓
校验图片内容 → 保存成果 → 发出成果事件
~~~

P02 保存服务配置与能力信息；P04 管理实际工具授权；P10 接入图片生成并检查图片成果。聊天服务与图片服务可以采用不同配置，不把文字模型的连通性当作图片生成能力。

## 可实施路线

OpenAI 官方提供独立 Images API，生成请求可发送到 /v1/images/generations；还可通过 Responses 中的图片生成工具进行多轮生成或编辑。独立图片入口优先实现 Images 适配器，Responses 工具路线按实际模型能力单独适配。[官方图片生成说明](https://developers.openai.com/api/docs/guides/image-generation)

模型标识由服务配置提供，不在工具接口中写死某个当前型号。兼容服务是否支持相同参数、尺寸或返回格式，须逐项实测，不能仅凭接口路径相同就判定兼容。

## 适配器应处理的内容

- 输入：提示词、可选输入图片、尺寸、格式，以及服务配置和凭据引用。
- 输出：经过校验的本地成果、媒体类型、像素尺寸、来源服务、请求标识及实际返回的用量。
- 错误：认证失败、额度不足、超时、空图片、坏编码或服务不支持的参数，必须作为失败保留；不自动重试或换服务。
- 取消：关闭本地连接不等于撤销已提交的远端生成；保留是否可能已提交的状态，避免恢复时重复收费。
- 凭据：由后端读取，不写入界面日志、图片元信息、成果文件或导出包。

## P10 的实际验收

需要具备用户可用的图片服务配置。成功结果要真实返回图片，检查文件可打开、尺寸正确、来源可追踪。错误场景要证明不会显示虚假的“生成成功”。P00 此项只完成接入路线核对。
