# P12 历史备份与恢复

日期：2026-10-04。程序 `0.1.0-alpha.12.2`，数据版本仍为 11。本批接续 T-P12-03，实现所选文件历史的完整导出、预览、导入和恢复；完整会话、项目资料、模型配置、技能、记忆迁移及清理仍待接续，不代表整个 P12 已完成。

## 用户怎样操作

在已绑定项目文件夹的任务中打开“文件与终端 → 修改历史 → 备份与导入文件历史”。

1. 勾选要备份的历史记录，选择一个新的保存位置，输入两次备份口令，保存 `.wphistory` 文件。每条记录包括修改前和修改后的版本；不存在的版本也保留其状态。
2. 在目标项目的任务中选择备份、输入口令，先预览记录数量、内容大小和相对路径。已有同名文件会明确列出。
3. 确认后只添加到目标项目的历史列表，不改项目当前文件；再次导入同一份备份到同一实际目录不会重复添加。
4. 在历史列表查看差异并选择恢复。恢复仍要求执行模式、原权限审批及当前文件版本核对；覆盖前保存当前内容，便于再恢复。

口令至少 12 个字符，软件不保存口令，遗失后无法解密。备份按原字节保存用户选中的历史文件，因此文件本身的敏感内容同样在加密备份内。应用模型凭据、认证头、浏览器登录资料和操作系统内的版本库密钥不作为设置或密钥材料导出。这个文件历史备份不包含当前项目所有文件，也不替代完整资料迁移。

导入记录绑定目标目录的实际身份，保留原任务、操作、版本编号、时间与来源。来源来自备份内容，不是外部作者签名。嵌套路径的父文件夹不存在或不可读取时，预览会说明；恢复前需要准备对应文件夹。本批不自动创建整棵项目目录。

本页独立选择版本的导出入口需要源任务绑定的项目目录仍能打开。`0.1.0-alpha.12.14` 的任务档案入口可以在原项目目录离线时导出任务已保存的文件历史，见 [任务与助手档案迁移](P12-任务与助手档案迁移.md)。完整目录树与其它资料的统一迁移仍待接续；保留原应用数据不等于已经完成这些迁移。

## 执行与数据边界

```text
选择已保存的版本 → 解开本机加密版本 → 用独立口令加密备份
                                              ↓
目标项目：完整核验 → 展示预览 → 确认 → 写入目标加密版本库和历史
                                               ↓
                                 另行选择恢复 → 原审批 → 修改项目文件
```

使用独立的 `HistoryTransfer` 管理命令，不把口令放入普通工作区操作参数、模型工具、事件或命令去重表。沿用已有 `SecretInput` 的调试输出脱敏和释放清除。界面只在内存持有口令，成功后清空输入框，不写本地存储。原生选择框仅允许主应用窗口调用。

后台一次处理一个历史迁移，普通任务与界面仍可运行。全局执行设置变化会取消当前操作，下一次显式请求可重新发起；应用彻底退出标记关闭并取消，不能由旧排队请求重新开启。文件访问本身仍受系统响应时间影响，不承诺任意设备上的即时中断。

导出临时文件从第一字节起就是加密数据，完整写入并同步后才发布，目标已存在时拒绝覆盖。P04 旧文本版本逐个读取、核对后进入本机加密版本库，再用统一路径导出；不会把整个数据库复制进包中。

导入先完整校验所有对象，不先插入历史记录；再次读取并验证后用目标本机密钥重新加密。数据库用单次事务登记导入回执、全部历史及事件，失败全部回滚，重启可识别已完成导入。预览指纹绑定备份内容、目标任务、目录身份和有效设置；确认时重新核对。

`0.1.0-alpha.12.14` 修复同一路径多个版本的导入冲突：整批回执继续防重复，每个历史版本单独保存为不执行的导入操作，保留最初来源与原时间。备份格式仍是版本 1，无数据库版本变化，不重新执行旧文件操作。

失败或中断可能留下已经写入、但没有历史引用的加密对象；不会留下只写一半的历史记录或改动项目文件。迁移时不自动删除这些对象；后续提供的离线清理入口按完整引用集合回收，见下方“版本保留与数据清理”。

## 备份格式与容量

- 固定头 `WPHIST01`，格式版本 1，随机 16 字节盐值；使用现有 ring 0.17.14。
- PBKDF2-HMAC-SHA-256 固定 600000 次，导出密钥只服务当前随机盐值的备份。该参数是本批工程选择，参考 [OWASP 的 PBKDF2 参数说明](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#pbkdf2) 与 [ring 接口文档](https://docs.rs/ring/0.17.14/ring/pbkdf2/fn.derive.html)，不声明取得密码模块认证。
- 清单和每个唯一文件对象分别使用 AES-256-GCM，随机 12 字节 nonce，头与顺序编号作为认证附加数据。清单也加密；不在包外暴露文件名和任务来源。
- 按 SHA-256 去重并核对文件原始字节。读取按单个文件进行，最多 64 MiB；单次最多 128 条历史、256 MiB 去重内容；清单最多 1 MiB。
- 拒绝未知格式、异常长度、重复版本、相对路径逃逸、Git 内部路径、链接或重解析路径、缺失内容、认证失败和多余尾部数据。格式不使用可执行脚本或压缩包路径展开。
- 本地 FileRevision 增加可选 `origin`，旧记录缺失此字段时正常读取。没有删除或迁移旧表，没有把历史原文混入普通脱敏内容对象。

## 版本保留与数据清理（alpha.12.15）

设置 → 数据清理与恢复初始状态。提供未引用内容回收、旧文件版本保留、归档根任务整组永久删除、只读档案移除、当前数据目录与凭据清空。任务组包含全部后代助手；项目原文件不会因为移除记录而删除。独立导入档案保留到用户另外选择删除它为止。

清理预览不改动记录。预览要求先暂停运行中的工作，列出所选任务/版本/档案数量与当前总量；确认指纹绑定数据库内容和具体选中记录，防止预览之后编辑数据或保留天数跨过边界而多删。一般清理输入 DELETE，清空全部数据输入 RESET。

确认后桌面停止引擎及其受管理子进程，再启动不含模型、调度器和插件的离线助手。数据库的引擎锁及稳定父目录的维护/更新独占锁，阻止其它进程同时产生引用。完成后用户重新启动软件。

版本保留按每个文件的最低版本数与“早于多少天”同时筛选，一次最多 128 条、64 MiB/份、去重 256 MiB。待清理版本先写入应用数据目录以外的新 WPHIST01 文件，使用至少 12 字符口令；同步写盘并完整解密校验后才在事务中移除记录。不能创建、无法解密或原内容损坏时不删版本。备份可由原“修改历史 → 备份与导入”入口恢复。保留策略不会改变当前项目文件；早期 P04 记录另外保留已清理标记，防止查询历史时重新生成它们。

整组删除一次移除成员依赖、等待、运行、附件和历史引用，保留命令及恢复回执作为防重复标记。定时任务历史的来源链接置空，记忆及其旧版本的已删任务链接解除，文字出处保留；其它任务和项目保留。删除失败时事务回滚。恢复过又删除的任务不会因重复导入被偷偷重建。

回收分两部分：普通脱敏内容沿用完整数据库引用检查；加密版本从文件历史、附件、尚未完成的操作、档案索引、迁移回执和浏览器成果登记出发，继续读取加密文件计划的嵌套引用。保守保留无法证明无用的内容，遇到缺失、损坏或目录链接明确报告。完成操作的临时执行说明与捕获缓存会释放，已保存版本和过程输出仍受引用保护。数据库删除成功后若磁盘回收失败，会明确区分“记录已处理、回收待重试”，不声称回滚成功。

清空先核对项目及独立任务绑定的文件夹没有放在应用数据目录内部，然后事务清空记录，保留凭据清理重试日志及受保护文件夹，只处理固定应用自有子目录与诊断日志。根目录未知文件和项目文件保留，不跟随链接或重解析目录。模型/扩展凭据使用原引擎启动路径对应的命名空间，图片凭据和本机版本密钥只按本数据目录登记的引用清除。系统凭据失败时保留重试记录；重启只接续这一已经明确确认的清空，不启动原任务。所有文件与凭据处理成功后清除重试日志并整理数据库空闲页。这不是物理磁盘安全擦除功能。

清空只处理当前数据目录；手动导出的口令包、其它目录和应用更新留下的恢复副本不在其中。删除本机版本密钥后，依赖此密钥的旧本地数据副本可能无法再解密，所以界面提醒先导出独立口令保护包。更新副本有单独的预览与确认清理入口。离线清理助手随桌面进程结束，不留下后台清理服务；已确认但未完成的清空在下次启动依据日志接续。

Windows 卸载器默认保留资料，另有独立的“清空历史与凭据”勾选；静默、被动和更新卸载不执行清空。被其它程序占用或清理失败会停止卸载，保留可重试的程序入口。详见 [安装设计](P12-安装与环境设计.md)。
