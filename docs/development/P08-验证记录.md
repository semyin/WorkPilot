## 发现与修正

- Node 的管道协议、跨源框架、弹窗与网页确认框使用真实浏览器验证。首次 DOM 点击没有带用户动作标记，测试页弹窗被阻止；补齐固定动作的标记。确认框同时阻塞 DOM 回复的问题改为先报告待处理弹窗，由下一次明确动作处理。
- 旧官方测试浏览器缓存启动报错 spawn UNKNOWN。下载新的官方 Playwright 测试运行环境到本项目 `.local` 后可启动；未修改用户日常浏览器或系统安全设置。此测试环境不随产品分发。
- 初次扩展读取选中页地址为空，构造 URL 报错。改为仅按已选择标签 ID 查浏览器公开目标信息，不能选择无关页。见 [扩展首次失败](../../artifacts/workpilot-p08-2026-10-03/evidence/companion-first-failure.json)。
- 登录保留测试最初使用会话 Cookie，不能据此要求重启持久化；测试改用明确有效期的合成 Cookie。同时修正专用浏览器关闭时立即终止导致未落盘的问题，等待正常退出后才使用超时清理。
- 页面加载期间新框架导航会拒绝本次读取。测试夹具针对只读快照等待页面稳定后再读，不重试任何改变页面的动作；保留 [导航竞争失败](../../artifacts/workpilot-p08-2026-10-03/evidence/navigation-race-failure.json)。
- 启动与停止同时发生时，原取消通知可能早于实际启动，留下迟到连接。Rust 从接收请求时记录取消代次，并在启动前后核验；Node 同步撤销正在建立的连接。修复后真实启动/停止竞争测试通过。见 [初次失败](../../artifacts/workpilot-p08-2026-10-03/evidence/lifecycle-first-failure.json)。
- 界面选择框/连接码补充明确可访问标签；查询不再把 JSON 字段名称当页面文字；读取新页面时清掉旧选择并禁用忙碌中的选项，防止选择被迟到读取覆盖。深色输入框使用现有主题颜色。
- 其余测试准备问题包括合成模型配置需要取实际 profile 字段、Windows 构建时测试正占用旧引擎、严格检查要求合并可折叠条件。修正测试/构建顺序及代码格式后通过；不将准备失败写成产品功能通过。

最初专用测试失败也保留：[弹窗](../../artifacts/workpilot-p08-2026-10-03/evidence/safety-first-failure.json)、[登录与退出](../../artifacts/workpilot-p08-2026-10-03/evidence/safety-second-failure.json)。各失败报告与最终通过分开存放。
