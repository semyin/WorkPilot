## 本轮发现及修正

1. 类型扩大后调整管道对象的内存布局，修正编译检查提示；生成的前端类型与 Rust 保持一致。
2. 设置下拉框补齐明确标签，修正隐藏导入控件的样式；真实桌面重测通过。
3. 增加跨文字/推理片段的密钥遮盖，防止同一密钥拆到多条事件中绕过完整字符串过滤。
4. 检查发现最初的小图片样本 CRC 不正确。替换为有效 PNG，并让本机模拟服务校验图片头、数据块 CRC 和解压内容；三协议桌面图片测试重新通过。
5. 初次升级测试漏建测试专用备份目录，初次桌面测试读取了未加 test 子目录的路径；修正测试构造后重跑通过。真实应用一直通过统一目录规则创建备份和测试目录。
6. 保存模型时允许暂不填写模型，方便先读取模型列表；真正发起推理请求前仍强制选择模型。

## 性能样本与限制

同机原桌面回归的单次启动观察约 581 ms；20 次停止到终止观察 p95 约 249 ms；按钮反馈 p95 9.5 ms，事件展示 p95 88 ms。完整原始样本在回归报告。它们不是云端模型速度、模型取消 p95，也不是跨设备性能承诺。

后端与界面有明确容量限制，详见适配说明。未做 4 小时长跑、全部服务商兼容、缓存/阶梯计费、系统凭据库异常恢复队列、原厂图片理解质量或跨平台实机验证。取消不能撤回已经到达服务端的请求，也不能保证服务端不计费。
