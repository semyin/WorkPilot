# P06 工作台与记录

日期：2026-10-02。桌面仍使用 React / Tauri 2；所有任务、消息、权限和记录来自原有 Rust 引擎。本阶段没有另建模拟任务系统。

## 界面与数据

```text
项目、任务列表           当前任务对话               详情
真实文件夹绑定    →      模式、模型、有效权限   →    权限与具体审批
名称搜索、归档           排队、编辑、取消、引导       独立成员与交付
独立任务                停止、人工继续               步骤、成果、完整记录
```

左右栏可隐藏、拖动或用方向键调整宽度。语言、主题、宽度与收起状态存入本机数据库。普通首页不再显示 P00 的固定示例项目；原技术验证页只通过 `?diagnostics=1` 进入，供基础回归使用。

新增 `WorkspaceAction`、`WorkspaceQuery`、`WorkspaceData`，继续走现有命令通道。动作有持久化回执；失败明确返回错误，不以界面操作成功代替引擎执行成功。主工作台使用普通区域语义，模型和项目设置才是对话框。

## 项目、任务与排队

- schema 6 增加项目规则、目录身份、配置版本、任务归档标记、界面设置和记录导出回执。升级沿用迁移前独立备份。
- 文件夹通过现有 `Root::open` 核验实际目录与身份，不靠路径字符串前缀授予权限。选择文件夹使用 [Tauri 官方 dialog 插件](https://v2.tauri.app/plugin/dialog/)，固定 Rust 依赖版本 2.8.1；使用异步回调，限主视图调用。
- 项目指定的模型、权限、规则与目录用于新建任务。已建任务保留创建时的绑定；修改项目设置不会悄悄移动已有任务。没有指定模型时仍按原有默认模型规则解析。
- 列表只显示根任务，成员从协作面板进入。搜索名称、按项目筛选和归档均读数据库，分页每页 48 条；归档保留任务树和文件来源。运行中的任务或开启调度的团队不能归档，归档任务需要恢复后才能继续。
- 排队消息编辑、取消同时核对所属任务、原内容编号和未交付状态。已经交付的消息不能改写。编辑保留旧事件内容，新版本也写事件；引导继续沿用 P03 的安全边界。
- 输入区收到入队回执后立即刷新队列；重开、换任务只查询，不重新发送。重命名与归档不修改用户项目文件。

## 对话、附件与完整记录

对话由原始目标、真正交付的用户消息、已完成的模型输出组成，不把上下文摘要当作历史原文。每页 16 条，每条显示最多 8,000 个字符，较长内容可以打开分页原文。

当前附件支持每个不超过 8 KiB 的 UTF-8 文本文件，总输入不超过 16 KiB。文件名和正文进入可见输入框，并确实随要求发送。图片、Office 与更大文件仍按 P10 接入，当前不伪装支持。

展示用详情保留最新 64 个步骤、最多 128 条消息及 32,000 字符的当前输出片段；完整执行上下文仍在数据库。工作台不再从第一条事件重放到现在，所选任务约每 150 ms 读取有界详情。流式展示只表示最近片段；完整模型输出保存在记录中。

记录查看每页 64 条；旧“完整事件”入口每页 128 条。搜索包含所选任务及其下级成员的事件和已保存正文，每个后台扫描批次最多 2,048 条、返回最多 64 个命中，并在约 150 ms 批次预算后返回游标。单个文件搜索按块读取，不以展示页长度截断搜索。搜索可以停止，界面不无限累积命中。

导出使用独立只读数据库快照，写入本机数据目录下新的 `exports/records-*` 文件夹：

| 文件 | 含义 |
|---|---|
| `events.jsonl` | 所选任务及成员的全部已保存事件，首行说明格式与版本 |
| `objects/` | 事件、消息、检查点、工具结果、文件版本引用的完整已脱敏内容，文件名为内容校验值 |
| `README.txt` | 读取方式与边界 |

只从数据库登记的所属关系收集内容；不会追随模型正文中伪造的其他任务内容编号。相同导出请求返回原结果；中途退出的临时文件不被当作成功导出。导出是记录查阅包，不代替 P12 的全量备份、还原和迁移。

记录搜索、导出最多同时执行两个后台作业，不占用任务调度线程。复制读取整条已保存内容；超过 8 MiB 时明确要求完整导出，不静默只复制可见页。成果栏显示最近 128 个已登记成果版本；更早来源保留在完整导出中。

## 权限、设置和窗口

任务标题处显示当前有效模型、模式和权限；右侧继续展示 P04 的精确审批和 P05 的独立成员记录。审批操作始终携带原任务与审批编号，切换任务不能转移审批对象。

模型设置、并发上限、权限默认值和数据位置连接真实接口。保存语言或主题不会触发权限配置，也不会暂停任务；修改全局权限仍沿用 P04 的暂停及审批失效规则，界面明确提示。

关闭窗口隐藏到托盘，任务继续；托盘打开原窗口；彻底退出会停止自有后台进程。重开中断任务仍需人工继续。托盘文案随界面语言更新。

`WorkspaceNotice` 只提供本机待处理事项，当前展示输入、审批及错误入口。系统通知和托盘提醒策略仍依赖 O-01/Q44，没有把建议当成用户确认。文件编辑、终端与回退属于 P07，浏览器属于 P08，技能和插件属于 P09。
