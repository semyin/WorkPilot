# P12 任务与助手档案迁移

更新日期：2026-10-04。程序 `0.1.0-alpha.12.9`，SQLite 数据版本仍为 11。

这是 Q41/T-P12-03 的一批实现：整个主任务及助手的已保存记录可以加密备份，并在另一份 WorkPilot 数据中导入查阅。**当前导入的是只读历史档案，不能从档案恢复执行。** 完整会话恢复、附件标记转换和统一多项目迁移继续保留，不能把本批算作完整 AT24 或 P12 验收。

## 使用入口

设置 → 任务与助手档案迁移。

1. 停止主任务、助手及文件操作，选择一个主任务。可切换到已归档任务，列表分页加载；所有助手自动包括在内，不允许单独导出某个成员。
2. 选择新的 `.wptask` 文件位置，输入并重复至少 12 个字符的口令。已有文件不会覆盖，口令丢失后无法找回。
3. 在目标 WorkPilot 选择该文件、输入口令，点击“核验并预览任务档案”。核验整个文件后显示任务树、消息/过程记录数、正文容量以及本包未包含的附件、文件历史数量。
4. 确认后加入“已导入的任务档案”。按类别分页查阅，展开保存的正文和关联正文；“全部保存正文”可以独立查看每个已保存内容对象。
5. 已导入档案可使用新口令另存，保持原档案编号和内容。重复导入、重启后再导入或同一档案重新加密再导入，不会增加重复档案。

原任务、原消息顺序、排队状态和所有工作区文件保持原样。导入不创建可执行任务，不启用旧审批，不调度助手，不触发模型或工具，也不更改全局模型、权限、定时和项目设置。

## 本批内容与边界

包含选定主任务及全部后代助手的 29 类已保存记录：

- 任务、助手身份、用户消息与排队位置、运行结果。
- 会话配置和上下文、历次运行、检查点、模型/工具步骤、已保存效果与人工核对结果。
- 助手分工、父子与依赖关系、交付、审查、接替关系、协作开关与等待记录。
- 工具调用、审批内容、工具正文、模型连接检查。
- 文件工作区操作、操作正文、旧版受管理文件变动、旧版成果及版本。
- 命令回执、事件、事件正文关联。

引用的已保存正文按原字节和摘要搬迁，包含长消息、模型结果、工具输出、上下文压缩后的历史与交付内容。当前界面的消息 128 条、步骤 64 条限制不用于导出；按数据库中的完整所选任务集合查询。模型当初没有保存的输出无法补造。

这不是数据库复制。表名和范围由程序固定，档案中的数据不会作为 SQL 或命令执行。原始编号只用于展示来源和历史关联，不成为目标环境的活动任务编号。历史中的路径仅作为文字保留，不访问或修改其指向的项目文件。

未包括：当前项目文件、附件/图片原文件与解析缓存、P07 以后加密文件版本库、工具的加密待执行快照、浏览器登录、凭据、定时计划、项目/记忆设置、扩展安装及环境。附件原文、文件版本等需继续使用各自已存在的迁移入口；跨包引用和自动恢复关联尚未实现。即使档案中能看到原附件编号或文件路径，也不表示原附件/文件内容已经包含在此包。

## 持久化与保护

- 新增独立管理命令 `task_archive`，包含导出、核验、导入、列表、分页读取和已存档案另存。口令使用 `SecretInput`，不进入命令历史或事件日志。
- 格式标识 `WPTASK01`、版本 1，沿用已有 PBKDF2-SHA256 和 AES-256-GCM 分帧加密。文件头、帧次序、清单与每份原文字节均核验；错误口令、损坏、遗漏/重复内容和尾部附加数据拒绝。
- 只接收固定记录类别和有效任务树；摘要、数量、内容引用需一致。嵌在工具/模型文本里的内容编号不能用来拉取另一任务的资料：来源导出只从所选任务记录的真实内容关联列建立清单，标题、计划或正文中的普通编号文字不建立读取权限。
- 导出在保存线程内取一致记录集；实际运行、排队运行或文件操作进行中会拒绝。仅有尚未执行的新任务 `queued` 状态不算运行中。
- 源已登记凭据出现在早期内容时拒绝导出；目标也会重新检查自己已登记的凭据。历史模型配置的凭据定位信息清除，密钥库不读取、不搬迁。不能保证自动识别用户自己粘贴但从未登记的所有未知秘密，应将口令与备份妥善保管。
- 核验阶段不保存解密内容；确认导入后先写入本机内容库，再在一次 SQLite 事务中登记内容与档案。失败或提交前取消不会留下半份可见档案。可能留下未引用内容，回收仍属版本清理待办。
- 本机档案正文与原来的会话记录使用同一内容库，**不是口令加密的本机保险库**；口令保护的是导出文件。已存档案无需重复输入口令即可查阅。
- 独立档案回执绑定清单摘要。同编号不同内容拒绝；确认指纹绑定实际加密文件与当前数据目录；重新加密文件需要重新预览。未新增数据库表或数据版本迁移。
- 档案索引中的正文加入已有内容回收器的保留集合。清理未引用对象后，档案仍可查阅和再次导出；分页时临时生成的行文档可以重建，不作为原数据的唯一副本。

## 容量与验证入口

每份最多 33 个任务（主任务加 32 个助手）、5 万条记录、4096 份正文；结构化记录索引最多 8 MiB，单份内容最多 64 MiB，总内容最多 256 MiB，加密清单最多 1 MiB。本机档案库最多 128 份；超限明确报错，不截断导出。此阶段不提供删除档案或清理来源任务的入口。

核心代码：`crates/contracts/src/task_archive.rs`、`crates/storage/src/task_archive/`、`crates/workbench/src/transfer/task_archive.rs`、`apps/desktop/src/task-archive/`。所有维护代码仍执行 1000 行限制。

可复现命令：

~~~text
npm run check
npm run test:task-archive
npm run build
npm run test:task-archive-desktop
npm run package:p12
~~~

实际检查结果、失败与修正保留在 [P12 验证记录](P12-验证记录.md) 和 [本批预览](../../artifacts/workpilot-p12-task-archive-2026-10-04/README.md)。本机隔离数据测试不等于物理换机、干净安装、macOS/Linux 或人工体验验收。
