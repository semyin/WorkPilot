# P12 统一迁移与未决操作核对

更新日期：2026-10-04。接续 Q41 / T-P12-03，数据版本仍为 11。最终程序与验收结论以 [文档索引](../README.md) 和 [P12 验证记录](P12-验证记录.md) 为准。

## 用户入口

设置 → **完整资料迁移**。一次选择多个项目，逐项勾选模型配置、记忆、主任务、技能/插件和未安装草稿，填写当前文件的相对路径。主任务自动包含后代助手、附件原文和保存的文件版本。

导出为一个 .wpmigrate 文件，由至少 12 个字符的口令保护。已有文件不覆盖。模型密钥、浏览器登录、系统凭据和模型凭据引用不进入迁移包。

读取备份后：

1. 为每个原项目填写新名称和现有目标文件夹；不同原项目在统一入口使用不同目录，不静默覆盖或合并。
2. 为每个历史原文件夹选择目标项目。普通项目提供建议，但必须核对；一个任务过去操作过多个目录时可以分别映射。
3. 预览配置、记忆、任务、历史、所选当前文件、扩展及冲突，同时列出未决工具、审批、文件操作和协作等待的原记录。
4. 确认后分步导入。成功部分有持久回执，失败显示具体结果，再次读取同一包可按保存的目标映射继续；不重复创建内容。
5. 当前文件独立进入新的“迁入项目文件”任务，通过现有工作台审批后才写入。恢复任务、历史和附件本身不会修改项目文件。
6. 任务需手动继续；扩展保持停用，模型密钥重新填写。未决操作另须逐项人工核对。

原有独立迁移入口继续保留。统一入口以项目作为选择单位；只搬独立模型配置时仍可使用模型设置中的原有导出导入。

## 未决操作的恢复规则

恢复允许包含尚未执行的调用、待审批操作、原协作等待以及效果未知的操作，但不恢复这些记录的执行权。

- 原档案和原结果完整保留。原批次中保存的结果仍在历史中；没有确定结果的调用封存为“迁移未重放，实际效果需核对”，不伪造成功，也不断言原操作没有发生。
- 原审批不进入活动审批表；旧命令和协作等待不放回调度队列。目标任务使用请求审批、命令关闭、手动继续。
- 新任务带有持久核对闸门。已有排队消息、直接点击继续、应用重启以及主任务尝试启动子助手，都不能绕过它。
- 工作台显示每一项原操作与记录，要求用户说明实际观察到的结果和允许的后续处理。保存说明只解除闸门、加入上下文，不连接模型、不执行工具；之后仍须手动继续。
- 新动作必须重新读取目标状态并经过当前权限/审批。旧审批编号、旧动作编号都不能执行原操作。
- 再次迁入另一位置时，历史核对说明保留，但有此类未决来源的任务重新要求核对新的目标位置。

人工核对使用管理动作 recovery_status / resolve_recovery，不暴露给模型工具。

## 多项目、原目录与来源关系

任务档案另增“分别映射多个项目和原文件夹”。mapped_restore_preview / mapped_restore 要求每个原项目和历史目录有明确映射，逐任务选择模型。有模型历史时继续匹配原协议、模型名称及服务地址。

任务、会话、助手、消息、附件、历史版本使用新编号。团队依赖、接替、任务资料和每个目标项目边界重新关联；旧编号只保留为来源，不成为跨任务工具别名。

统一迁移复用设置包的来源表，把当前记忆及旧版本的来源任务关联到同一批次的新任务。来源任务没有被选择时保留文字出处，不猜测同名任务。只更新本批创建的记忆，重复导入不重置后续用户修改。

当前文件保留相对路径，写入所选新项目，和该项目下的历史对应。目标已有文件在预览时拒绝；确认后发生变化仍由工作台再次核对，绝不静默覆盖。

## 历史命令与已删除任务

迁入任务的历史 run_command 输出支持 read_command_output 分页。只登记来源任务实际拥有的 stdout/stderr，不把正文中的任意内容编号当作读取许可。其它任务不能用旧步骤编号读取此输出。

永久删除恢复任务后保留恢复回执。再次使用同一档案返回“已经恢复，但目标已删除”，停用打开入口，不偷偷重建任务。统一迁移回执也保留并显示已删目标。

永久删除“迁入项目文件”任务时，在同一删除事务中把对应回执收缩为任务/操作编号与已删除标记，释放清单和文件原文引用；不把去重记录当成永不清理的备份。另一个活任务、待审批计划或独立导入档案仍引用的内容有合法用途，继续保留。仅当任务、相应版本、独立导入档案及其它有效计划都不再引用时，才由清理回收原内容；不承诺删除一个任务就无条件物理删除所有共享内容。重试导入不能复活已删任务，旧文件准备请求在读取清单前明确拒绝。被删恢复任务的历史查询索引一并移除，原恢复去重回执继续保留。

## 格式、容量与故障处理

格式 WPFULL01 复用 PBKDF2-SHA256 和 AES-256-GCM 分帧实现，验证文件头、清单、帧次序、大小和内容摘要。组合既有设置/扩展/任务/文件结构，不复制数据库或本机密钥。

- 每包最多 16 个项目、16 个任务组；组内人数、附件、历史版本仍遵守原任务档案限制。
- 每项目最多 128 个模型选择、128 条记忆、128 个当前文件、32 个扩展选择；记忆和扩展包含保存历史，目标总量另行检查。
- 全包去重内容最多 256 MiB，单份内容最多 64 MiB，组合资料说明最多 16 MiB。扩展资源编码计入说明容量，较大资源仍可使用独立扩展迁移。超限拒绝，不截断。
- 导出任务和助手前须停止运行中的工作。已保存历史不要求原目录在线；磁盘当前文件要求原目录可访问。
- 核验与预览不创建活动任务、项目或扩展。确认后的文件暂存受本机加密版本库保护，未引用对象由清理功能处理。
- 项目设置、任务组、扩展各自沿用既有事务或安装回执；跨文件/插件/数据库使用分步持久回执。失败保留已完成项和错误，不宣称全局原子回滚。
- 文件写入保留“部分完成也不自动重做”的规则，操作记录可查看写入范围。停止或崩溃后不自动再次写文件。
- 确认指纹绑定包内容、项目名称、实际目录身份和历史映射。开始后的同一包不能偷偷改目标；重复导入不会重新启用插件、重置权限或复活删除记录。
