## 已保留的失败与修正

1. 环境受限后的测试 PowerShell 无法自动导入权限查询模块；测试改用 .NET 只读权限接口，没有修改系统 Node 权限。
2. 通用 Git 在 AppContainer 下不能规范化工作目录。继续保留失败证据与 T-P12-04，不扩大项目外读取范围，不自动切换完全访问。原有工作区审批提交另行验证成功。
3. Python 默认输出编码无法表示中文；执行环境固定 UTF-8 后，中文输出及文件通过。
4. 默认 NSIS 整体压缩遇到大数据块映射错误；基于原模板改用逐文件压缩后成功，Office/WebView2 都保留。第二次构建较慢，但正常完成，没有中止；后续仍需优化构建用时。
5. 安装测试最初把其它目录的预览进程一并拦住；核对 NSIS 按具体目标文件检查占用后，改为只保护临时安装目标，现有用户进程保留。
6. 测试电脑提供两个 Node 路径，测试脚本最初错误拼成一个路径；明确取当前查找顺序的首个程序后，完整安装后检查通过。首轮安装/卸载本身已成功，失败记录未删除。
