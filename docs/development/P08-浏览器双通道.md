# P08 浏览器双通道

日期：2026-10-03。在 P07 的真实任务、权限、工作区操作和文件历史上接入浏览器。数据版本仍为 schema 7。产品基线没有改变；这仍是开发预览，日常 Chrome/Edge 的本轮用户授权体验待集中补测。

## 两条连接路径

```text
React 浏览器工作区 / Rust 模型执行循环
                  │
      Rust workbench：模式、权限、单次审批、操作记录
                  │
      自有 Node.js 工具进程：固定动作、连接归属、有界消息
          ┌───────┴───────────────────┐
   专用 Chrome / Edge          本机一次性连接码
   独立任务目录、调试管道        Rust native messaging 转发程序
   退出时关闭自有进程            用户授权 Companion 扩展
          │                     指定标签页与其新建页面
          └───────┬───────────────────┘
       共用固定 DOM 操作、目标检查、截图、文件传输
```

DOM 指浏览器实际提供的页面元素，例如按钮、输入框和链接。模型只能选择已经读取到的元素编号，不能把网页文字或模型生成的脚本交给浏览器执行。

- 专用通道通过 `--remote-debugging-pipe` 与当前已安装的 Chrome/Edge 通信，不开放浏览器调试网络端口。每个任务/浏览器品牌使用独立目录，不复制日常配置。每任务最多一个在线专用实例。
- 日常通道使用新的 `extensions/companion`，保留 P00 Probe 扩展及注册。用户在浏览器扩展页面加载 Companion，再在目标页明确点击连接。扩展使用 `chrome.debugger`、`nativeMessaging` 和 `activeTab`，没有全站内容脚本或 Cookie 读取权限。
- 本机连接仅监听 127.0.0.1 随机端口；连接码含 192 位随机数，十分钟有效、一次消费、区分 Chrome/Edge。扩展 ID 与 native host 的允许来源固定匹配。码只显示给手工连接界面，不进入模型会话或操作导出。
- 本轮自动扩展测试采用官方测试版 Chromium 的隔离已有会话。它证明扩展、本机程序和引擎实际联通，不代替日常安装版 Chrome/Edge 的人工授权验收。

## 固定操作与任务接入

统一动作包括启动专用浏览器、列出标签页、新建/关闭、导航、读取/查找元素、点击、填写、截图、处理网页确认框、上传和下载。模型使用 `browser_sessions` 与 `browser`；先确认本任务的连接，再读取页面，执行后重新读取结果。浏览器版本、通道、标签页与状态在工作区展示。

模型启动专用浏览器也进入操作审批。已有日常会话必须由用户连接，模型不能生成连接码、任意接管标签页或开启任意执行脚本。聊天/规划模式只提供读取类动作；启动连接、恢复自动操作及改变页面需要执行模式，归档任务不能执行。

右侧浏览器工作区与手工操作共用后端；手工启动、连接、接管是用户明确动作。请求审批和帮我批准下，改变网页的动作仍需具体确认；完全访问直接执行。这沿用高风险外部动作须确认的规则，并未让执行模型为网页动作自行提权。

审批保存具体参数、任务、当前权限、项目身份、连接、页面代次及元素描述。确认只能消费一次，执行时再次核对。页面重载、目标文字/值/链接/表单地址发生变化后，原操作失败，需要重新读取和发起。页面的诱导指令不能改变模式或读取项目外文件。

## 目标、登录与生命周期

- 控制范围是当前任务的专用标签页，或用户连接的已有标签页及其新建页面/弹窗。其它既有标签页不能通过猜编号访问。iframe 分框架读取，跨源框架也有独立引用；框架失败显示错误。
- 同一连接内串行执行动作。界面定时刷新只读状态和操作记录，不刷新页面元素，避免悄悄使模型正在使用的引用失效。
- 页面元素脚本运行在独立上下文，输入值当作数据。使用 DOM 点击、输入和事件；不是全桌面鼠标键盘操控。要求可信硬件事件、封闭 Shadow DOM、画布控件的站点可能需要手动接管。
- 密码字段不由模型填写，DOM 记录不读取密码值。登录、验证码、系统下载弹窗等由用户手动接管；恢复后必须重新读取页面。截图可能包含当前页面的可见个人信息，只在模型明确支持图片时发送，不自动切换模型。
- 专用登录状态保存在该任务独立目录内，保留范围由网站 Cookie 有效期与浏览器规则决定。正常关闭等待浏览器落盘，不立刻强杀。日常登录保留在原浏览器，不复制 Cookie/凭据。
- 关闭主窗口只隐藏，浏览器工作继续。彻底退出关闭自有专用浏览器与工具进程，仅断开日常扩展，不结束用户的浏览器。取消任务、修改相关权限、停止浏览器操作会撤销连接；启动过程也核验取消状态，防止停止后迟到的连接重新生效。
- 扩展断开/停用、浏览器退出、撤销调试或重载导致旧引用失效；不会改选其它页或静默重连。进程异常退出后的明确新建连接可重启工具，旧动作不重放。外部动作超时只报告不确定结果并断开相关控制，用户/模型须先核对页面。

## 文件与记录

上传从 P07 已授权项目读取当前字节，核对旧版本，不能让扩展读取任意本机路径。记录参数和实际源文件版本，不记录传输用的整段二进制。上传和点击提交都是可能产生外部效果的动作。

下载使用浏览器自身登录上下文读取明确链接，将字节交回 Rust，经原文件版本核对后完整替换、加密保存版本，并登记来源 URL、路径、大小与版本。成果入口中的回执是这些元数据；原始二进制在项目文件和加密版本库，不冒充可直接预览的文本成果。可在“文件与终端”的历史查看和恢复。

专用浏览器禁止默认下载落入系统下载目录。已有浏览器仅在受控标签页拦截明显 HTTP 附件响应，不修改日常浏览器的全局下载设置。显式下载工具覆盖可读取的 HTTP(S) 链接；blob、浏览器内部地址、系统保存框、脚本生成的复杂下载暂不支持，应手动接管。不能将 HTTP 拦截称为所有网站下载的系统沙箱。

读取/截图及改变页面均留操作记录。原始参数用既有加密版本设施保存，可见正文/普通日志沿用脱敏；网页内容标记为外部资料。模型调用按执行步骤 ID 查找已保存回执，审批后继续复用结果，不重复点击/填写。中断与未知外部效果不宣称已撤回。

## 当前容量与边界

| 项目 | 上限或行为 |
|---|---|
| 在线/待连接会话 | 全工具最多 16 个；每任务一个专用实例 |
| 每连接标签页 | 最多控制 32 个 |
| 页面读取 | 最多 12 框架；每框架 250 个可见元素、48,000 字符正文，截断有标识 |
| 模型视图 | 最多 30 元素，每框架 700 字符正文；查找 query 获取其余目标；完整记录另存 |
| 上传 | 512 KiB；受 native messaging 单条宿主消息 1 MiB 约束 |
| 下载 | 8 MiB；HTTP 错误和超限不落盘 |
| 截图 | 当前可视区域 PNG，最多约 3 MiB 字节 |
| 固定动作 | 单次输入文本等最多 16,384 字节；不允许任意 JavaScript |
| 重启 | 连接需重新建立，专用目录保留；不自动重放未知外部副作用 |
| 平台 | Windows 实测；macOS/Linux 的注册、权限与退出待 P14/P15 |

这些容量是本轮明确工程边界，不是性能指标。没有完成真实站点全覆盖、四小时长跑、干净机器安装、扩展商店发布或浏览器升级过程验收。Firefox/Safari、原生电脑操控保持原计划。

## 工程入口与复测

主要文件：`crates/contracts/src/browser.rs`、`crates/workbench/src/browser.rs`、`crates/runtime/src/browser.rs`、`services/browser/driver.mjs`、`extensions/companion`、`crates/browser-bridge/src/bin/companion.rs`、`apps/desktop/src/BrowserPanel.tsx`。

`npm run test:browser-engine` 验证专用通道、权限/文件/多框架、停止和模型接入；`npm run test:browser-companion` 需要本机主机已注册与官方测试 Chromium；`npm run test:ui` 含新面板真实引擎流程。构建后 `npm run test:browser-desktop` 验证原生桌面及隐藏/退出。只对本机专用测试目录和网页执行。

开发注册步骤见 [Companion 安装说明](../../extensions/companion/README.md)。分发预览附带 Node.js 及许可证、浏览器驱动、Companion 和独立注册脚本；普通 Chrome/Edge 使用系统已安装版本。完整安装升级仍属 P12，不宣称当前预览已通过干净系统验收。

官方依据：[Chrome debugger](https://developer.chrome.com/docs/extensions/reference/api/debugger)、[Native messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging)、[官方测试浏览器侧载说明](https://playwright.dev/docs/chrome-extensions)。接口依据不等于 WorkPilot 所有浏览器版本已验收。
