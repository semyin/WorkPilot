# P07 文件历史与开发工作区

日期：2026-10-03。实现环境：Windows 11 x64。数据结构版本 7。

## 用户入口

选择一个已绑定项目文件夹的任务，点击对话上方“文件与终端”。工作区包含文件、修改历史、终端、Git 四个页面。任务的聊天、规划和执行模式继续生效；修改文件、运行命令和提交需要执行模式。

- 文件：逐层浏览目录、搜索文本、新建文本文件、编辑、保存、重命名、删除，打开所在目录或调用系统默认应用。
- 修改历史：按项目实际目录汇总来源任务、操作、时间、前后版本；查看文本差异、原始大小和校验值，恢复修改前或修改后的版本。
- 终端：运行真实 PowerShell 命令或指定程序及参数，查看输出、运行状态和停止结果。可为本机服务登记预览端口。
- Git：读取真实仓库状态，查看暂存和未暂存差异，勾选文件后提交。提交不包含推送。

关闭工作区返回对话，不停止命令。关闭主窗口隐藏到托盘，命令继续；停止任务、改变执行权限/模式或彻底退出会停止所属后台进程。重开后不自动重跑中断命令。

## 实际结构

```text
文件与终端界面
      │ 工作区命令
      ▼
Rust 引擎 → workbench：文件版本、审批、终端、Git
      │                   │
      │                   ├─ storage：操作记录、来源、内容引用
      │                   └─ 加密版本库：文件原始字节
      ▼
tools 共用目录写入锁 → platform 系统进程边界
      ▲
模型文件工具、模型命令共用这条保护路径
```

- 新增 crates/workbench；桌面外壳只处理默认应用打开、独立预览窗口，不直接替引擎修改项目文件。
- schema 7 新增工作区操作、文件版本、执行前快照和输出归属表。P04 的已有文本版本按引用接入同一历史页面，不重写原事件。
- 操作通过 Workbench 命令执行，并发查询最多 8 项，后台修改最多 4 项；实际目录内的修改与模型工具共享排他执行权。
- 操作输入、输出和两路命令正文登记为内容引用，供完整记录补读、搜索、导出及垃圾回收保留。查看具体操作可展开完整参数和结果。
- 查询与文件读写在专用后台工作中执行；界面不承担执行状态，也不依赖窗口存活维持任务。

## 文件版本与恢复

新工作区修改和受管理命令保存实际文件字节。版本使用 ring 0.17.14 的 AES-256-GCM 加密并校验；密钥保存在操作系统凭据库，磁盘只有密钥编号和加密对象。找不到原密钥或数据校验失败会明确报错，不偷偷建立新密钥覆盖旧库。

恢复步骤：读取指定版本 → 核对当前文件身份和内容 → 保存当前版本 → 写入恢复内容 → 登记一次新变化。外部修改后，旧保存/恢复请求失效；编辑框中的未保存内容保留，用户可以重新读取后决定。

替换文件先在同目录写完整临时文件并同步，再替换目标。Windows 保留原访问控制规则；Unix 保留权限位，但本轮没有 Unix 实机验证。新建和重命名使用不覆盖已有目标的操作。拒绝目录逃逸、符号链接、硬链接、特殊文件和直接修改 Git 内部文件。

P04 的 write_file 继续使用原有 1 MiB 文本与敏感内容限制，已有版本通过兼容入口展示。当前加密版本库用于工作区编辑、恢复和受管理命令；不能把新库存在理解成旧写入工具已取消所有限制。

## 真实覆盖范围与容量

| 内容 | 当前处理 |
|---|---|
| 内置编辑 | UTF-8 文本不超过 256 KiB；原样保存换行和字符 |
| 版本文件 | 单文件最多 64 MiB，二进制按原始字节保留 |
| 命令前后快照 | 最多 4096 文件、1024 目录、合计 256 MiB；超限在执行前拒绝 |
| 目录列表 | 每层最多显示 256 项，可进入子目录或使用文本搜索 |
| 图片预览 | PNG/JPEG 不超过 4 MiB；其它二进制显示大小、校验值与文件头 |
| 文本差异 | 展示前 3000 行差异，可分别查看完整的可读文本版本 |
| 命令输出 | 标准输出、错误输出各最多 4 MiB，超限结束并报告；保存两路实际正文 |
| 单次命令时限 | 手工工作区最多 24 小时；模型工具仍最多 5 分钟 |

命令快照排除 .git、node_modules、target、dist、.venv、.cache、.local、.workpilot-data、.test-results，以及工作区自身临时文件。历史界面说明覆盖边界。执行后超限或核对失败会保留执行前记录并报告“核对未完成”，不自动重跑。

脚本和终端记录的是执行前后两个可观察版本，不保证期间每一次瞬间写入；外部应用并发修改可能出现在核对结果中，因此来源表示“该次操作期间观察到”，不是确定某一进程写入了每个字节。重启补记明确标为 recovered，同样不代表原进程退出时的精确快照。重命名只在文件身份与内容均可唯一对应时关联，否则按删除和新增记录；恢复作用于选定路径，不做整个项目回滚。

大于 64 MiB 的文件不进入当前版本读取/恢复路径，可打开项目所在目录后使用外部软件。Word/Excel/PPT 此阶段保留版本、恢复和外部打开；内容预览按 P10，内置完整编辑按 P16。浏览器下载和插件尚未作为产品通道接入，分别在 P08/P09 接入同一历史边界后补测。

## 审批与命令

手工工作区修改在“请求审批”和“帮我批准”下显示具体确认；完全访问直接执行。模型工具的独立审批机制沿用 P04。确认绑定任务、目录身份、参数、目标版本、权限版本与模式；只可使用一次，重启也不会重复消费。改配置或停止父任务会停止该分支命令。

Windows 普通权限命令使用 AppContainer（系统提供的隔离进程，无网络能力）；完全访问按当前账户权限执行。Job 只管理本次启动的进程树，停止不查杀同名程序。环境不传入模型密钥，仅提供执行需要的标准变量。

PowerShell 的目录用一个仅指向已授权项目的文件系统盘符建立，避免隔离进程虽已进入项目、PowerShell 却退回系统盘。终端目前为命令与流式输出面板，不是可持续输入的交互式伪终端；需要输入密码或交互选择的程序请在外部终端处理。

长命令持有该项目的修改锁，期间其它受管理写入排队；界面明确提示，用户可停止命令后编辑。这是保证前后版本可核对的当前策略，不宣称支持任意服务与写入同时进行。

## Git 与预览

Git 提交前比较分支提交、暂存区和所选文件版本。只提交选中路径；其它暂存和未暂存修改保留。不自动重置、清理或推送。需要安装 Git，并设置提交身份。合并冲突、外部过滤器、变化后的状态会被拒绝。内置提交禁用钩子、文件监测脚本和签名；需要这些项目流程时使用项目终端。失败可能留下所选新文件的“待添加”标记，错误中会提示，不清理用户暂存内容。

静态 HTML 在禁止脚本的受限框架中显示。运行预览仅在完全访问任务中提供：先登记空闲端口，再核对监听端口确实属于本操作的进程树。页面在独立窗口显示，没有桌面文件和命令权限，导航限制在该服务地址。停止后不可重新打开旧端口；关闭文件工作区同时关闭该预览窗口。

## 接续与限制

- 主模块：crates/workbench；接口：crates/contracts/src/workbench.rs；页面：apps/desktop/src/FileWorkbench.tsx；Windows 边界：crates/platform/src/tool_process/windows.rs。
- 加密文件版本尚未纳入可跨机器迁移的备份；完整记录导出是脱敏过程记录，不是原始项目与凭据备份。P12 必须一起处理数据库、加密对象与密钥迁移。
- 当前不自动清理加密版本，不提供不可逆的团队历史批量删除。整体归档继续可用；避免先删除来源再留下无归属文件版本，清理策略与 P12 备份迁移一起落实。
- macOS/Linux 的进程隔离、预览归属及系统权限保留仍需对应阶段实机验证。跨平台结构保留，不声称其它系统已可交付。
