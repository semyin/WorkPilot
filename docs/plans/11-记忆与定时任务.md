## 目标

实现用户确认的长期记忆，以及程序在托盘时仍可执行的本机定时任务。两者都可查看、修改和停用。

## 实现任务：记忆

1. 区分任务历史、项目规则、长期记忆与文件检索索引，不把所有历史聊天都作为“已记住的偏好”。
2. AI 提出记忆候选，附来源和适用范围；用户确认后才进入正式记忆。
3. 提供查看、搜索、修改、删除、撤销和导出；保留必要来源与确认记录。
4. 任务加载记忆时按全局/项目范围筛选，已删除内容不再通过旧检索索引重新出现。
5. 初期用本地索引和明确引用满足检索，是否引入额外语义检索组件由实际规模决定。

## 实现任务：定时

1. 创建、编辑、启停计划，配置项目、目标、模型、权限、触发时间及时区。
2. 展示下次执行与历史执行，将每次触发变成独立、可查看的任务。
3. 调度器由本地引擎持有，窗口隐藏后继续；彻底退出或关机后不执行。
4. 在有效权限内运行；需要审批时等待用户，不因任务是定时触发而跳过权限。
5. 触发去重、重叠运行策略、错过执行记录、时钟变化、睡眠唤醒和重新启动后的行为明确。
6. 工程建议：同一计划默认不重叠；错过触发不自动补跑，用户可手动立即运行。
7. 完成/错误/审批事件接入通知接口；Q44 已于 2026-10-04 确认软件内、Windows 系统通知和托盘提示，三渠道保持可配置，实现在 P13 补齐。

## 生命周期规则

关窗继续适用于普通任务、子助手和定时任务。真正退出时终止正在运行的本地执行，不留一个未告知用户的常驻系统服务。

重新打开隐藏窗口只是重新显示状态；重新启动已退出的应用，历史中断任务需人工继续。调度器安排未来触发，不自动重试上次失败的运行。

- 托盘后台运行的完整演示。

## 测试与验收

- [x] 未确认的记忆不会被当作已确认偏好使用。（Windows 固定模型自动验证；真实模型内容质量待用户体验。）

- [x] 窗口关闭后，普通及定时任务仍真实执行，重新打开不重复启动。（Windows 原生桌面隐藏、同时运行与重新显示检查通过。）
- [x] 彻底退出后任务不运行，下一次启动不批量补跑错过计划。（原生桌面退出中断运行任务、重启不恢复，未来一次性计划记为错过。）

- [x] 定时任务的模型错误遵守中断规则，子助手接替规则与手动任务一致。（主模型 429 不重试；子助手单独失败，主任务显式委派新助手后完成。）
- [ ] 关闭通知权限不会让审批记录或任务结果消失。（Q44 已确认；P13 应用渠道开关和通知定位检查已通过，Windows 系统权限/实际弹窗与用户体验仍单列补验。）
