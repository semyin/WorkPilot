# P14 macOS 适配与发布

状态：未开始  
前置：P13  
关联需求：Q04、Q12c、Q13、Q28、Q38、Q39、Q40、Q47  
完成后进入：[P15 Linux 适配与发布](15-Linux适配与发布.md)

## 目标

复用同一执行核心，交付经过 macOS 实际验证的版本。当前没有 Mac 实机，必须在这一阶段补齐测试条件。

## 实现任务

1. 确定支持的 macOS 版本和 Apple Silicon/Intel 范围；按目标准备构建和运行环境，未测架构明确列出。
2. 验证 Tauri 的网页显示、中文输入、双语排版、文件选择和预览，处理与 Windows 的差异。
3. 适配菜单栏入口、Dock、关闭窗口和明确退出的行为，维持隐藏继续、退出停止的产品规则。
4. 适配凭据存储、文件权限、路径、命令环境、进程组和取消。
5. 分别打包对应架构的引擎、Node、Python、浏览器、Git 和文档组件。
6. 专用浏览器与现有 Chrome/Edge 通道在 macOS 重新验证；首批范围不自动扩展到 Safari。
7. 验证项目终端、Git、预览服务、文件版本和外部办公软件编辑回流。
8. 确定应用签名、公证、安装、更新和卸载的发行条件，真实条件未具备时先标内部测试包。

## 交付物

- 明确系统与处理器范围的 macOS 安装包。
- 与 Windows 的平台差异及功能一致性记录。
- 实机、依赖、菜单栏生命周期、浏览器和更新验证。

## 测试与验收

- [ ] 真实 macOS 环境验证核心 AT 场景，不能只在 Windows 上交叉编译。
- [ ] 窗口隐藏后运行继续，明确退出后引擎及自有工具结束。
- [ ] 中文输入、文件路径、权限提示与系统凭据行为正确。
- [ ] 目标处理器的随包组件实际执行成功，未测架构不宣称支持。
- [ ] 两条浏览器通道、图片生成、定时和迁移均通过。
- [ ] 更新和数据库迁移失败保护用户数据。
- [ ] 真实发行包的签名/安装行为符合所声明分发方式。

对应验收：AT01—AT30 中适用于该平台的场景。

## 阶段边界与风险

没有 Mac 测试环境时标记“待外部条件”，同时可以完成可验证的共享代码工作。原生电脑操控仍是后续能力，不因 macOS 适配自动纳入。
