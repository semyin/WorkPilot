# P13 Windows 首版验收

状态：开发及本轮短时验证完成，待外部环境和用户体验验收。当前 alpha.13.4；四小时连续测试按用户明确要求取消，长期稳定性未验证。

前置：P12，且 P00—P11 的相关验收已通过  
关联需求：Windows V1 全部范围，重点 Q08、Q28、Q38、Q39、Q43、Q45、Q47、Q48  
完成后进入：[P14 macOS 适配与发布](14-macOS适配与发布.md)

## 目标

将各模块集成为可以日常使用的 Windows V1。首版是完整通用平台的第一个正式版本，不能用单个成功演示代替全部范围。

## 实现与收敛任务

1. 核对 [需求基线](../00-需求基线.md) 的首版清单及 [AT01—AT29](../04-验收与质量标准.md)。
2. 修复集成后的数据、权限、取消、队列、子助手和文件一致性问题。
3. 使用真实模型服务分别完成三协议验收；明确模型、服务、能力与测试时间。
4. Chrome、Edge 和专用浏览器分别完成完整连接与操作，不用一条通道替代另一条。
5. 办公文件与图片生成实际核验成果；编程任务检查代码修改、运行预览和 Git 范围。
6. 验证中英界面、三模式、三档权限、模型配置、消息队列与引导的组合。
7. 长任务、多任务、多助手、关闭窗口、彻底退出和异常恢复组合测试。
8. 验证安装、升级、导入导出、本地诊断及随包工具环境。
9. 完成使用说明、已知问题、兼容清单和发布说明，向用户提供体验清单。

## 平台通用性验收

用同一个执行器处理不同类型目标，例如代码修改、网页资料整理、文件处理和图片创作。样例用来检验通用能力，不把这些样例写成软件仅有的固定流程。

必须包含：多个助手独立产出后汇总、成员失败后显式接替、执行中引导、外部文件修改冲突、原工具结果不确定后的恢复。

## 性能与稳定性

- 按已校准目标测量启动、输入响应、事件展示和停止。
- 分别报告引擎、界面、浏览器和文档工具资源占用，不能将模型等待误算成 Rust 调度慢。
- 使用固定模拟模型负载测试平台性能，再用真实服务验证体验，二者分开报告。
- 长时间运行检查内存增长、未回收工具进程、数据库膨胀和关闭后的工作残留。
