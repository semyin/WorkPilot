## 4. 模型接口

| 编号 | 官方资料 | 必须注意的边界 |
|---|---|---|
| S09 | [OpenAI：Chat Completions 与 Responses](https://developers.openai.com/api/docs/guides/migrate-to-responses) | 消息、输出对象、工具结果关联和流事件不同，要独立适配 |
| S10 | [OpenAI：工具调用](https://developers.openai.com/api/docs/guides/function-calling) | 模型提出工具请求，应用执行并回传结果 |
| S11 | [OpenAI：流式响应](https://developers.openai.com/api/docs/guides/streaming-responses) | 处理分片及最终结束事件，不能只拼接文本 |
| S12 | [Claude：Messages 流式响应](https://platform.claude.com/docs/en/build-with-claude/streaming) | 文本、工具等内容块与消息生命周期分别处理 |
| S13 | [Claude：API 错误](https://platform.claude.com/docs/en/api/errors) | 流中也可能出错，SDK 可能自动重试；WorkPilot 明确禁用模型自动重试 |

三类协议并不保证所有代理服务与原厂行为完全相同。服务地址、认证方式、模型能力和字段差异都需要具体兼容记录。本文没有选定或承诺某个模型的价格、额度和账号可用性。

## 5. 浏览器与扩展

| 编号 | 官方资料 | 对计划的影响 |
|---|---|---|
| S14 | [Chrome：远程调试限制](https://developer.chrome.com/blog/remote-debugging-port) | 日常默认用户目录不能直接沿用专用自动化浏览器的启动方案 |
| S15 | [Chrome：调试扩展接口](https://developer.chrome.com/docs/extensions/reference/api/debugger) | 已登录通道的候选，需验证授权、支持命令与断开行为 |
| S16 | [Playwright：操作前检查](https://playwright.dev/docs/actionability) | 专用浏览器驱动候选，检查元素后操作并验证实际结果 |
| S17 | [MCP 架构](https://modelcontextprotocol.io/docs/learn/architecture) | 工具连接的标准接口，与平台的模型执行循环分层 |
| S18 | [Pi 官方项目](https://github.com/earendil-works/pi) | 可参考模型适配、执行内核与上层会话分层；本项目主引擎自研 |

Chrome 的说明不自动证明 Edge 所有版本具有完全相同限制。两者都要在 P08 实测。浏览器扩展授权和已有会话连接属于用户可见流程，不通过复制浏览器凭据实现。

## 6. 资料使用规则

- 记录资料版本/核对日期；阶段开始前复查对应接口。
- 官方资料说明能做什么，本项目测试说明实际上做到了什么，二者分开。
- 调研到的产品代码、私有引擎和安装包不作为未经核验可直接分发的依赖。
- 更新依赖前记录版本与变更影响，不能用“最新”代替可重现的构建清单。
