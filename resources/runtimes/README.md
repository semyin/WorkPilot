# 随包运行环境清单

P00 先核对来源、发行形态和体积，P12 再完成打包。这不是已经包含全部工具的安装包。

具体版本、官方地址、字节数和检查方式见 [manifest.json](manifest.json)。当前只记录 Windows x64；macOS、Linux 各自需要匹配的平台包，不能重用 Windows 可执行文件。

| 组件                         | 当前核对的压缩包/安装包大小 | 用途与处理                                            |
| ---------------------------- | --------------------------: | ----------------------------------------------------- |
| Node.js 22.23.2              |             35,683,585 字节 | 插件、浏览器工具所需运行时；放在应用私有目录          |
| Python 3.12.10 嵌入包样本    |             11,133,606 字节 | 展示 Windows 随包形态；P12 交付前选择仍维护的补丁版本 |
| Playwright 浏览器样本        |            205,123,748 字节 | 开发测试样本启动受阻；不能直接当作已验证可分发浏览器  |
| PortableGit 2.55.0.windows.5 |             58,960,208 字节 | 编辑工作区所需 Git；保留运行库、版权和源码提供安排    |
| LibreOffice 26.8.0 样本      |            374,906,880 字节 | 办公文件转换候选；需验证独立配置目录和离线安装        |

大小为原始下载资产，不是解压后占用或最终安装包大小。没有把这些体积简单相加后宣称最终安装包已确定。

本次开发已使用机器上现有 Node、Python、Chrome、Edge、Git；没有将用户电脑上的日常浏览器、办公软件或其登录资料复制进 WorkPilot。

## 打包时必须落实的项目

1. 下载官方资产并固定校验值，保存其自身许可、第三方通知及必要的源码提供信息。浏览器组件的许可不能只写 Playwright 的许可。
2. Node 包和 Python 库锁定到具体版本，准备离线依赖；原生库需匹配操作系统和处理器架构。
3. 图片、文档转换涉及的字体单独选定可分发来源，不把用户机器字体自动打入包。
4. WebView2 运行时是 Windows 桌面宿主的依赖。P12 需明确离线安装策略，不能依赖首次联网下载来满足“随包环境”的要求。
5. Rust 是开发工具链，用户运行编译后的 WorkPilot 不需要安装 Rust。P00 的两个主程序合计约 7.4 MB，不能将这个数字冒充包含 WebView2、浏览器和办公工具的整包体积。

## 当前结论

Node、Python、Git 和办公转换组件都有可核对的官方分发来源。浏览器自动下载样本当前未能启动，其包内条款与实际可运行资产仍需继续核对；这是 P12 的具体待办。P00 的浏览器技术路线通过系统已有 Chrome/Edge 的独立目录测试及日常扩展授权测试分别验证。
